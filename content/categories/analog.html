📐 机器学习排序在现代微架构策略上的局限——当排序结果依赖隐藏的微架构状态时，没有模型稳定胜过随机
arXiv:2608.01041 · cs.AR / cs.LG · 2026-08-02 · Yanxin Zhang, Shayne Wadle, Yuxuan Xiong, Zheyu Fu, Trivikram Krishnamurthy, Karu Sankaralingam
ML 预测器比周期级仿真快得多地估计处理器性能。但在设计空间探索（DSE）中，有价值的检验不是复现通常的硬件排序，而是识别不同硬件配置在单个程序阶段上如何排序。本文在两种设计体制下评估四种 ML 预测器：结构参数（SP）体制（issue width、ROB size、cache capacity 等）与行为策略（BP）体制（预取与替换算法）。在 SP 体制下，聚合排序强，但「反直觉窗口（CIW，预期更慢的配置反而更快）」占五个具明确架构先验配对中非平局窗口的 22.4%，跨配对 CIW 匹配仅 23.3–39.9%，均低于 50% 随机严格排序参考；BP 体制则是另一种失败：真实平局占配对窗口 37.8%，多数严格配对仅差几个周期，没有模型族稳定胜过无特征多数基线（NeuroScalar、SimNet 低于基线，Concorde 与之统计持平，最佳 OneDSE 头仅 +2.1 个百分点）。信息论分析进一步表明该失败并非模型容量问题，而是排序结果依赖隐藏的微架构状态。

NEW  arXiv:2607.29076 · cs.AR · 2026-07-31 · Yuannuo Feng, Wenyong Zhou, Yuang Ma, Yizhe Chen, Wenshuai Yao, Yuxin Xie, Ngai Wong, Wang Kang（港大 / 北航）
模拟存内计算上的选择性 KV Cache 保护：抗噪 LLM 推理——困惑度自 33.91 降至 11.95（干净基线 11.06），动态 KV 编程行利用率 23.1%→91.2%

模拟存内计算（CIM）阵列被视为高能效 LLM 推理的有力基底，尤其适合线性层的权重驻留（weight-stationary）计算。但把模拟 CIM 扩展到注意力机制会遇到根本性挑战：KV cache 操作需要反复的原位权重更新，与权重驻留范式的错配使动态计算暴露在显著硬件噪声之下——这一关键问题此前几乎无人研究。本文首次系统研究模拟 CIM 阵列上的动态注意力计算，揭示初始 token 与近期 token 对硬件噪声具有不成比例的脆弱性。基于该 token 级洞察，提出分层 token 保护策略：把 sink token 与滑动近期 token 窗口留在更高精度的数字通路，把大宗 KV cache 交给模拟 CIM；并协同设计调度器，结合模拟编程、所有权切换与批量 MVM tile 组装，把数字侧开销控制在有界范围。在 9 个 LLM 上评测，模拟噪声下平均困惑度从 33.91 降至 11.95（干净基线 11.06），动态 KV 编程行利用率从 23.1% 提升到 91.2%。核心创新：为「模拟 CIM × Transformer 注意力」这一软硬件协同设计空白给出首个系统性刻画与可落地方案，对 AI 芯片的电路-架构协同优化（噪声容忍度建模、混合精度通路划分）具有参考价值。
