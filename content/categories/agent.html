⚡ VeriTrace：类人的时序探索补全智能体动作空间——首个在 VerilogEval-V2 上达成 100% Pass@1 的多智能体 RTL 调试系统
arXiv:2608.02878 · cs.AI · 2026-08-03 · Yu-Tung Liu, Cunxi Yu
现有 LLM 多智能体 RTL 生成系统在标准基准上卡在 ~95% 准确率天花板。VeriTrace 把这一瓶颈追溯到「不完整的调试动作空间」——现有系统限制了智能体可观察的信号、可查询的时间窗或二者，使调试退化为对电路行为的狭窄、预定视图做模式匹配，而非假设驱动的根因分析。VeriTrace 提出一个多智能体系统，其 Inspector 智能体在完整的调试动作空间上运作，独立控制信号选择、时间窗边界与迭代深度（即「智能体时序探索」Agentic Temporal Exploration），能形成失败原因假设、查询波形取证、迭代精炼理解，镜像人类验证工程师的探索过程。结果：VeriTrace 在 VerilogEval-V2 上达成 100% Pass@1，是首个在该基准上取得完美功能正确性的系统；在共享 Claude Sonnet 4.0 基座上，比最强复现基线高 +5.1%，证明「调试能动性」填补了最后几分的准确率缺口。

🤖 Zomboss：为新兴加速器重构智能体式 kernel 生成——把神经搜索锁进经验证的编译器边界
arXiv:2608.00894 · cs.AR · 2026-08-01 · Ruijie Gao, Jirong Yang, Barry Lyu, Haoran Jin, Nathan Bleier
新兴加速器常缺乏成熟的编译器后端，催生了「从架构文档 + 仿真反馈生成并修复 kernel」的神经智能体；但这类方法对每个工作负载都重复重建与负载无关的机器语义（指令行为、合法性约束、同步规则、内存协议）。Zomboss 主张把这些语义一次性编译为持久的符号化产物，让神经推理只聚焦负载相关的映射决策。Zomboss 是一个编译器中介的智能体式 kernel 生成框架：先把机器语义与合法性约束编译为可复用的映射接口，再用神经智能体在已验证的映射空间内优化负载相关决策。在 20 个 Gemmini + 36 个 PLENA 工作负载实例上，Zomboss 在全部 56 个实例上返回经验证的正确 kernel；相对编译器默认，Gemmini 上几何均值加速 3.34×、PLENA 上 1.10×；相对直接智能体式生成，推理 token 在 Gemmini 上减少 71.2%、PLENA 上 54.2%。这表明：编译器定义的符号接口把「原生 kernel 合成」变成了经验证的设计空间探索。

Can AI Agents Really Complete RTL-to-GDS? Lessons from Benchmarking Tool-Interactive EDA Workflows（FluxBench / FluxEDA）
arXiv:2607.17528 · cs.AI / cs.AR / cs.LG · 2026-07-20 · Jinyuan Deng, Zhengrui Chen, Xufeng Wei, Tianyu Xing, Chenyi Wen, Cheng Zhuo
提出 FluxBench，在统一 prompt、工具环境与技术库下系统评测 AI 智能体的端到端 EDA 工作流能力，覆盖开源工具链 RTL 生成与商用闭源 RTL-to-GDS 流（以 PicoRV32 为案例），评估 RTL 代码生成、迭代修复、工具反馈利用、逻辑综合、布局布线（P&R）与 ECO 自动化；并提出 Token ROI 成本效率指标。关键发现：即便同一基座模型，不同 agent 架构性能差距达 86.27%；任务性能相近时 Token ROI 可差 105.92×；PicoRV32 RTL-to-GDS 上 FluxEDA 端到端分数 97.94，优于带领域 EDA skills 的 Claude Code 达 8.39×。结论：仅靠领域 skills 不足，agent 系统设计与基座模型能力同样关键。Cheng Zhuo 组出品，呼应本站 AgenticPD / PDAgent-Bench 主线。

ArchEval: Measuring AI Agents as Computer Architects
arXiv:2607.03601 · cs.AR · 2026-07-03 · Chenyu Wang, Zishen Wan, Jeffrey Ma, Shvetank Prakash, Zhenting Qi, Haebin Do, Andy Cheng, Arya Tschand, Jiahe Shi, Yilun Du, Vijay Janapa Reddi
提出 ArchEval，评测 LLM 智能体在计算机架构设计与优化上的基准与平台。含 CPU 核机制、系统架构、存储系统、加速器、存内计算 5 大类 20 个挑战，背靠 8 个模拟器。每个挑战设三档设置：L1 完整 harness（有重复模拟器反馈）、L2 模拟器-代码容器（需自行组装工作流）、L3 仅智能体（提交前无可用反馈）。每轮报告基线归一化验证性能并记录完整轨迹，关联工作负载分析、模拟器工具使用、预测、约束处理与产物完整性。初测显示清晰边界：L1 下 4 个智能体均达/超基线；移除支持后暴露弱点（多数无法将模拟器源码转为有用实验，L3 预测常与验证结果不符）；L3 仅 GPT-5.5+Codex 高于基线（1.21x 几何均值、65% 胜率），性能建模通过率仅 15%。ArchEval 将今日智能体定位为有用优化助手而非自主架构师。

Computer Architecture's AlphaZero Moment：体系结构研究进入自动化发现时代
Karthikeyan Sankaralingam（University of Wisconsin-Madison）· 2026-03-31 · cs.AR
摩尔定律终结后，架构创新成为性能提升的主要杠杆，但人类驱动的研究已无法适应新时代。人类团队每代仅能探索 50–100 种设计，采样率不足 0.001%，而设计空间已达数百万甚至数十亿量级。作者提出"自动化创意工厂"替代方案：多层评估流程每周生成并评估数千候选架构，并利用部署遥测数据形成持续反馈循环。初步结果表明，此类系统可将设计周期从数月压缩至数周，探索设计数量远超人类团队。
核心预言：类比 AlphaZero 在棋类领域的突破，未来两年内纯人类驱动的架构研究将如同人类棋手与引擎对抗般过时。这是整个计算机体系结构领域的范式转变宣言，对 AI for EDA 研究共同体有深远影响。
