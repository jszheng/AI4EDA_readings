🛡️ RTLGuard：面向投毒 RTL 代码生成模型的轻量师生防御——小样本干净教师引导抑制后门行为（ICCAD 2026）
arXiv:2608.26049 · cs.CR / cs.AR · 2026-08-26 · Mahshid Rezakhani, Kimia Azar, Hadi Kamali
LLM 推动 RTL 代码生成自动化，使设计者将高层规格翻译为可综合硬件；但对预训练（第三方）微调模型的依赖引入关键信任问题——训练数据与适配过程不透明，攻击方（甚至模型提供方）可在微调阶段嵌入隐藏后门，使硬件木马在推理时被看似良性的 prompt 触发。本文提出 RTLGuard 缓解 AI 赋能 IC 供应链中的此类信任风险：不同于全参数重训练的高昂成本，RTLGuard 采用师生框架净化被污染 RTL 生成模型——(1) 在有限可信 RTL 数据上微调轻量「干净」教师模型；(2) 通过复合师生目标引导被投毒目标模型；(3) 引入特征对齐与知识蒸馏抑制恶意行为。在多种 LLM 架构上显著降低攻击成功率（ASR）同时保持功能正确性与可综合性。已被 ICCAD 2026 录用。属「前端 RTL / 安全」方向，针对 RTL 生成模型供应链投毒与后门威胁给出低成本防御。

🧩 Chiplet 与 LLM 时代的硬件设计与安全——统一分析 2.5D 系统攻击面 + LLM 驱动 EDA 流水线的原生威胁
arXiv:2608.05063 · cs.CR / cs.AI / cs.AR · 2026-08-05 · Johann Knechtel, Ozgur Sinanoglu, Paul V. Gratz, Ramesh Karri
半导体行业正经历向异构 2.5D 芯粒系统的迁移，以及 LLM 融入 EDA 流程的双重革命，二者剧烈扩张了硬件攻击面。本文统一分析：从针对 chiplet 系统（含 LLM 加速硬件栈）横跨架构 / 逻辑 / 物理层的攻击，到多种针对 LLM 驱动 EDA 流水线的利用；并综述利用 2.5D 拆分制造 + 有源中介层构建物理隔离信任根（RoT）的强防御，以及 LLM 系统如何反哺现代系统（含 chiplet）的硬件安全。连接「Chiplet 安全」与「AI4EDA 可信生成」。

NEW LLMs for Secure Hardware Design and Related Problems: Opportunities and Challenges

Johann Knechtel, Ozgur Sinanoglu, Ramesh Karri

首个系统性综述 LLM 驱动的硬件安全设计机遇与挑战，涵盖 EDA 综合（RTL 代码生成、测试平台自动化）、硬件信任（硬件木马检测）、安全设计（DFT 安全）、教育四大领域。深度分析 LLM 引入的安全风险：数据污染攻击、对抗性 ML 规避、数据记忆化导致基准失效。提出动态基准测试 + 激进红队测试应对策略，目标是构建安全可信的自主硬件设计生态系统。
