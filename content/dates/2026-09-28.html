⚡ VeriFormal-Agent：多智能体 RTL 生成-形式化验证闭环——从自然语言规格自动抽取 SVA 属性、用反例驱动修复，把 RTL 正确性从「仿真通过」升级到「可证明」

LLM 生成 RTL 的「生成-验证闭环」目前多依赖仿真（testbench 跑通即过），但仿真只能证明「某些输入下没错」，无法覆盖全部输入空间，隐含的规格违例会在下游流片阶段爆发。VeriFormal-Agent 在生成之后接一道形式化验证兜底：① Spec-Extractor（规格抽取器）把自然语言/契约中间表示（呼应本站 09-15 收录的 Spec2RTL-Agent 2609.11342 的 CDIR）自动转写为机器可检验的 SVA 属性与覆盖率目标；② Formal-Prover（形式化证明器）对接 JasperGold/CoSA 类形式引擎做全输入空间验证；③ CEX-Repairer（反例驱动修复器）一旦形式引擎给出反例（counterexample），就把它作为精确定位信号驱动最小 diff 修复，修复后再回灌证明器直至全部属性收敛。在 VerilogEval 与 RTLLM v2.1 子集上，相对「仿真-only」基线，隐含规格违例漏检率降 86%、下游功能逃逸降 73%；并产出一份可机器验证的正确性证书。属「前端 RTL / RTL-to-Specification 自动生成 + 智慧体协作的 RTL 生成-验证-反馈闭环」方向，把本站持续追踪的 Spec2RTL-Agent（生成-仿真-审查）→ VeriRAG（检索约束）→ RTLRepair-Agent（仿真定位修复）→ RTLReview-Agent（静态审查）主线，首次补上「形式化验证」这一最高保障层级，使生成 RTL 的正确性从经验性「能跑」升级为可证明。

📐 CellSizer-RL：强化学习驱动单元大小调整（cell sizing）与时序/功耗联合优化——把尺寸选择、缓冲器插入与拥塞协同进统一 RL 策略

布局后优化里，单元大小调整（cell sizing）——把标准单元在驱动强度/面积的不同尺寸版本间替换——是改善时序与漏电的基础杠杆，但传统做法是「先定尺寸、再插缓冲器、最后修拥塞」的串行流水线，局部最优叠加常引发全局回弹。CellSizer-RL 把三者建模为统一的序列决策：强化学习智能体在布局后图上逐区域决策，动作空间覆盖单元尺寸升级/降级、缓冲器插入位置与数量、局部拥塞疏导，状态编码融合局部时序路径 slack、功耗热点图与密度/拥塞图；奖励函数把WNS（最差负 slack）、总功耗与面积联合加权，并引入时序-功耗耦合守恒正则防止「降功耗导致时序崩」的跷跷板。在 ISPD/TCAD 基准与开源 OpenROAD 流程上，相对商业 PPO + 串行基线，WNS 改善 18%、总功耗降 11%、面积仅增 1.9%、迭代轮次降 33%。属「后端物理设计 / 强化学习在单元大小调整、缓冲器插入、布局后优化的应用」方向，把此前 BufFormer（2609.14357，缓冲器+尺寸联合）、DRVRepair-RL（2609.16342，DRV 修复）的 RL 决策从「单工序」推进到「尺寸-缓冲-拥塞」三工序协同，与本站关注的「RL 在布局布线、单元大小调整、缓冲器插入」细分直接对应。

🌡️ InterposerGNN：GNN 驱动 2.5D 中介层（interposer）互连-热-应力多物理场协同预测——在封装图上学三场耦合，秒级给出热感知、应力感知的互连规划

2.5D 硅中介层（interposer）把多颗芯粒拼在同一封装，其互连、热分布与机械应力深度耦合：高带宽 Die-to-Die 链路堆叠即热点，热膨胀又在中介层 TSV 处引入应力集中，而应力/热又会反过来限制互连摆放与供电。现有做法把三场当作三个串行 FEM/CAD 工具求解，每次迭代动辄分钟到小时级。InterposerGNN 把 2.5D 中介层建模为封装异构图（芯粒/TSV/微凸点/互连走线为节点，带宽、热阻、机械刚度耦合为边），用图神经网络在图上同时回归稳态/瞬态温度场、互连拥塞图与机械应力场，并引入热-力-电耦合物理残差正则（热流守恒 + 带宽守恒 + 应力-形变一致性）约束预测满足物理律；推理秒级输出「互连规划→热-应力」联合解，并给出可微分梯度提示。在 2.5D 开源 Chiplet 基准上与商业有限元/互连规划工具对齐，峰值温度 RMSE < 2.1°C、应力预测误差 < 4%、拥塞 F1 0.92；下游协同优化使中介层供电网络 IR drop 降 7%、关键链路延迟降 9%、应力热点数降 23%。属「后端物理设计 / Chiplet 系统的互连·热分布优化、多物理场 AI 分析」方向，把此前 ChipletNet-GNN（2609.13567，互连-热）、PowerChip-GNN（2609.15388，供电-热）、ChipletThermalGNN（2609.16588，热-拥塞）的单/双场预测推进到「互连-热-应力」三场全耦合，与本站关注的「Chiplet 多物理场 AI 分析」主题直接对应。

🤖 EDAgent-Bench2：端到端芯片设计智能体第二版标准化评测基准——覆盖 RTL→综合→验证→布局布线→签核全链路 80 子任务，新增工具调用可靠性与多智能体协作评分

当前「端到端芯片设计智能体」的研究缺乏统一、可复现的评测标尺：各家用不同流程、不同工具封装比 pass@k，结论难以横比。EDAgent-Bench2 在 EDA-AgentBench（2609.12031）与 ToolFail-EDA（2609.14723）基础上推出 v2 标准化基准：把芯片设计拆成 RTL 生成→综合→功能验证→布局布线→签核 五阶段的 80 个标准化子任务，每个子任务绑定固定工具容器（含开源 OpenROAD / 商业工具接口桩）与确定性 QoR 回传；并新增两类评分维度：① 工具调用可靠性（区分 flaky tool / 错误回退 / 幻觉工具名，呼应 ToolFail 的失败分类学）；② 多智能体协作效率（子任务交接的上下文损耗与重复劳动占比）。在 12 个主流设计智能体上评测，最优端到端一次通过率从 v1 的 23% 提升到 27%，但工具调用仍是首要瓶颈（占失败 44%，较 v1 的 47% 略降），多智能体协作效率与单智能体相当——说明「加智能体数量 ≠ 加通过率」。属「AI Agent / 评测基准·工具可靠性」方向，把本站持续追踪的 EDA-AgentBench → ToolFail-EDA → OpenEDA-Agent（2609.15600）→ EDAgent-SkillHub（2609.16723）的智能体评测与工程化主线，补上了「可复现、可横比」的标尺，与用户关注关键词「各种开源的针对 EDA 的 AI Skills / agents 新能力」直接对应——为技能市场里的技能质量提供了统一度量。
