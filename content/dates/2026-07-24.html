🎨 Chipmind 发布 RTL Canvas：业界首个工程师与 AI 智能体之间的"双向契约界面"，把芯片审查从文本 PR 搬上画布

瑞士苏黎世初创 Chipmind（2025-10 出 stealth，Founderful 领投 $2.5M 种子，团队源自 ETH Zürich）发布 RTL Canvas——业界首个工程师与 AI 智能体之间的"双向契约界面（bidirectional contract surface）"。工程师直接在 RTL 架构图上手绘设计意图（增删模块、跨层次/时钟域拖拽信号与总线、重路由外设），智能体写出的 RTL 改动以交互式视觉 diff 回流（新增 FSM/时钟域/逻辑门标绿、删除标红、未改动背景"ghosted"），并在合并进代码库前于实时 staging sandbox 中验证约束；画布本身成为"契约"——意图写其上、每次改动据其判定，只有双方都理解并同意的改动才落地代码库。
核心突破：把智能体交互从文本聊天升级为直接图形操控，把芯片设计瓶颈从"生成/测试代码"转移到"人类如何审查、信任、交互"。支持 VS Code / 浏览器 / GitHub Issues / @mention / MCP / ACP（多智能体编排、跨工具上下文共享、开放协议）；集成 Verilator / Yosys / OpenROAD / VCS / Design Compiler / PrimeTime / Xcelium / Innovus / Questa，兼容 OpenTitan / PULP / RISC-V。
核心看点：与本站已跟踪的 Cadence AuraStack / Synopsys.ai Copilot / Siemens Fuse / ChipAgents 同处"agentic EDA 审查层"竞争，直击"机器写 RTL 越多、人类审查越成瓶颈"的产业痛点（验证占芯片周期 60–70%，首流成功率从 ~30% 降至 2024/25 的 14%，70% 重流片源于设计错误）。来源：chipmind.ai。

🧭 AlphaRoute：把 LLM 当作语义策略优化器用于多目标 VLSI 全局布线 — ISPD 2025 上 MEMPOOL 溢出降 98.6%、ARIANE 溢出降 29.8×

VLSI 全局布线是 NP-hard 组合优化（在带容量约束的 3D 网格上分配信号网，最小化拥塞/线长/过孔），传统启发式依赖静态惩罚调度，在复杂拥塞拓扑上失效。本文提出 AlphaRoute：一个多目标自适应搜索框架，把"撕毁重布线（rip-up and reroute, R&R）"重塑为动态优化系统——引入基于 SHAP 的溢出分解隔离每网拥塞，驱动 3D Dijkstra 迷宫布线 + 自适应 PathFinder 策略做定向子图抽取。关键：AlphaRoute 把 LLM 当作语义策略优化器——在确定性知识图谱约束下，LLM 解读拥塞指标、动态调节惩罚参数。
核心结论：在 ISPD 2025 基准上，MEMPOOL 溢出降低 98.6%；在受限 ARIANE 设计上溢出 146,109（较 SOTA 降 29.8×），惩罚分数 S_orig=0.0538 vs SOTA 1.780。
核心创新：把 LLM 作为"受知识图谱约束的语义优化器"嵌入传统布线搜索回路，刷新 ISPD 2025 全局布线 SOTA——已被 IEEE LLM-Aided Design 会议 2026（Stanford）接收，代码已开源；延续本站对布线/可布线性（Prim-Dijkstra / CLDRoute）与"LLM+物理设计"主线跟踪。

📐 芯片布图规划结合凸与非凸优化 — 三阶段固定轮廓框架，MCNC/GSRC/HB+ 上 HPWL 平均改善 ≥1% 与 5% 超 SOTA

布图规划（floorplanning）是 VLSI 物理设计的关键早期阶段，质量直接影响互连线长、芯片性能与下游效率。本文提出一个结合非凸与凸优化的多阶段固定轮廓（fixed-outline）布图规划框架，分三阶段：① 初始布图——二次布局（quadratic placement）优化模块连通性，产出强网聚类的拓扑感知起点（但有显著模块重叠）；② 全局布图——Adam 投影梯度法求解最小化线长+重叠的非凸优化；③ 合法化——对数变换模型利用水平/垂直约束图在凸公式下消除残余重叠。
核心结论：在 MCNC、GSRC、HB+ 基准上，框架取得 SOTA 线长质量，平均 HPWL 较被测 SOTA 布图规划器降低至少 1% 与 5%。
核心创新：凸/非凸混合（二次布局 + Adam 投影梯度非凸 + 对数变换凸合法化）的布图规划流水线，刷新线长 SOTA——延续本站对布图/布局优化（DREAMPlace / GNN Placement / MAGE 宏布局）主线跟踪，作者含 EDA 知名学者 Jordi Cortadella。

🔬 Chiplet 基 AI SoC 的"已知良好可靠裸片（KGRD）"筛选形式化基础 — 从 KGD 到 KGRD 的约束推断 + 安全门控决策架构

基于 chiplet 的 AI 系统级芯片（SoC）快速增长，暴露出半导体测试方法的根本缺口：现有"已知良好裸片（KGD）"筛选只保证装配前功能正确，却不提供装配后可靠性寿命的概率保证。本文把 KGD→KGRD（Known Good Reliable Die）的过渡形式化为"不完整装配前可观测性下的约束推断问题"，提出四项 interlocking 贡献：① 贝叶斯概率风险模型，把装配前遥测映射到装配后失效似然，并给出可量化的可观测性偏差界；② 安全门控决策架构，提供可证明的装配后失效概率保证；③ 源自 Bayes 最优决策理论的"不确定性感知处置边界"；④ 约束闭环反馈机制，在不违反可靠性约束下实现一致的模型改进。
核心结论：N=4,000 合成裸片的蒙特卡洛仿真验证了全部四项理论性质，并确认安全保证在完整门阈值范围内一致成立。
核心创新：为 chiplet AI SoC 的装配后可靠性筛选建立首个形式化基础（贝叶斯风险 + 安全门控 + 闭环反馈）——延续本站对 Chiplet 互连/可靠性（Chiplet3D / Chiplet 互联标准化）与"多物理场/可靠性 AI"主线跟踪。
