RTLScout: Joint Agentic Code and Synthesis Optimization for Efficient Digital Circuits

作者：Felix Arnold, Ryan Amaudruz, Dimitrios Tsaras, Renzo Andri, Lukas Cavigelli

提出RTLScout，一个将 LLM 驱动智能体设计与电路级综合优化和算术架构搜索相结合的自主系统。LLM 智能体通过工具调用迭代编写、评估和精炼 RTL 设计，由 Yosys 和 OpenROAD 提供量化 PPA 反馈指导。引入多轮精英池框架，最佳设计和经验教训用于播种后续智能体运行。流程包含四个互补阶段：智能体代码优化、智能体门级重写、算术架构扫描、可选高强度门级精炼。在 IEEE-754 兼容的 16 位浮点乘法器（含亚正常数支持）上，RTLScout 相比 ASAP7 工艺基准设计面积减少 35%，延迟降低 45%。各阶段提供独立改进，高强度门级优化对已优化设计的精炼最有效。生成的帕累托前沿优于相同工艺下商用工具参考设计。

RTL优化 LLM Agent 逻辑综合 PPA优化 精英池 自主设计

arXiv:2606.07246 · cs.AR · 2026-06-05

MailoHLS: Multi-Adapter Structure-Aware Learning for Pareto-Driven HLS Pragma Optimization

作者：Elena Vouvali, Dimosthenis Masouros, Aggelos Ferikoglou, Dimitrios Soudris, Sotirios Xydis

提出MailoHLS，一个结合 LLM 语义推理与 GNN 结构建模的混合框架，用于目标感知的 HLS 编译指示优化。核心创新：通过交叉注意力融合结构嵌入，利用目标条件 LoRA 适配器和帕累托驱动优化，实现代码语义、结构依赖和设计权衡的联合推理。在已见和未见设计上，MailoHLS 实现最高 12.42× 和 8.4× 加速（几何平均 9.48× 和 4.97×）用于延迟优化，持续生成近帕累托最优设计。在完全未见应用上，达最高 10.2× 加速（几何平均 6.58×），超越高端 LLM 和先前方法，大幅缩小与帕累托前沿的差距。解决了 LLM 因顺序表示难以捕捉结构依赖和全局权衡这一根本局限。

HLS优化 LLM+GNN LoRA 帕累托优化 FPGA 结构感知

arXiv:2606.04126 · cs.AR / cs.AI / cs.SE · 2026-06-02

HighTide: An Agent-Curated Open-Source VLSI Benchmark Suite

作者：Benjamin Goldblatt, Paolo Pedroso, Farhad Modaresi, Ethan Sifferman, Matthew R. Guthaus (UC Santa Cruz)

推出HighTide，一个AI 辅助维护的演进式开源 VLSI 基准测试套件。核心贡献：(1) 覆盖多设计语言和工艺节点的多样化开源套件；(2) Bazel 增量 RTL-to-GDS 编译及远程缓存；(3) 12 个 AI 智能体技能覆盖设计生命周期、流程优化、工具参考、元维护，每个设计附带决策日志作为长期调优记忆；(4) RTL 编译验证确保稳定发布。HighTide 公开可用，随开源硬件生态增长而演进。这是首个将 AI Agent 直接嵌入基准套件维护的工作，代表了从静态基准到动态智能维护的范式转变。

VLSI基准 AI Agent 开源 RTL-to-GDS Bazel UCSC
