🇨🇳 芯和半导体 (Xpeedic) @ DAC 2026：发布 EDA2026 产品线 + 携手联想落地国产 EDA 首个 AI 实战闭环——建库—布局—规则检查—仿真优化，联想 AI PC 验证，设计效率 +50% / 仿真提速 80%+

芯和半导体在 DAC 2026（7/26–29，长滩）现场发布 EDA2026 产品线全新版本，并联合联想集团展示双方 EDA Agent 战略合作的最新研发成果——成为本届大会国产 EDA 唯一现场落地案例，标志国产 EDA 的 AI 智能体从战略共识进入可验证、可展示的实际产出阶段。
① EDA2026 三大能力升级（"AI 时代的系统设计领航员"）：
· 电热协同分析：板级仿真平台 Notus 新增电热双向反馈建模，电流场与温度场自动同步求解，配合网格复用 + 集群并行，把大规模单板仿真从"天"级压缩至"小时"级；已在超聚变服务器单板验证。热应力平台 Atlas、Boreas/Janus 把该能力延伸到封装级与芯片级。
· 光电联合仿真：ChannelExpert 与 Metis 协同支持 CPO 封装的超高频 SI、光电跨尺度建模与热应力耦合，在易卜半导体 2.5D 封装项目验证，仿真规模较传统方法提升 20 倍。
· AI 多智能体部署：依托 XAI 智能平台，六大智能体系统性融入 STCO 全流程，实现多物理场 AI 智能体协同与 Chip-to-System 端到端自主优化，已在联想 AI PC 等产品中规模化落地。
② 与联想集团 EDA Agent 闭环（PCB 研发全流程 AI 设计闭环）：AI Agent 贯穿"建库—布局—规则检查—仿真优化"——AI 建库模块自动生成维护元器件库；AI 自动布局承担智能化版图布局；AI Checklist 完成设计规则自动检查；仿真环节 CCT AI 完成 DDR 通道自动检查、高速链路 AI 优化模块完成参数寻优。已在 联想 AI PC 主板 PCB 验证：设计环节人工介入大幅减少，元器件库自动建库效率 +50% 以上；仿真环节迭代次数减少，SERDES 全链路优化仿真寻优效率 +80% 以上。
③ 生态合作：与诺瓦星云宣布 LED 显控芯片 AI+EDA 战略合作；与联想的合作自 2025-11-19 签约，聚焦 EDA 全流程智能化。
核心看点：与三大 EDA 巨头的"数字端 agentic AI"（Cadence ChipStack / Synopsys AgentEngineer / Siemens Fuse）不同，芯和定位"多物理场 AI 智能体协同 + Chip-to-System 端到端自主优化"，把 AI 智能体延伸至 SI/PI/电磁热耦合等物理层设计环节，覆盖 Chip→Package→Board→System 全链路——是本站已跟踪的国产 EDA AI 进展（华大九天 3DIC / 启芯宸光 DeepChip / 算苗科技 TokenPU）中，首个给出可量化验证指标的 AI Agent 落地案例（+50% / +80%+）。来源：中国证券网、网易科技、芯和半导体。

NVIDIA · 官方新闻稿 / NVIDIA 中文博客 · 2026-07-26（DAC 长滩）/ 2026-07-30 中文报道 · Agent Toolkit 扩展：PhysicsNeMo + CUDA-X（cuDSS 直接服务 EDA）+ Nemotron 3 Ultra × ACE-RTL

🟢 NVIDIA 扩展 Agent Toolkit：纳入 PhysicsNeMo + CUDA-X（cuDSS 直接加速 EDA 稀疏线性系统），Nemotron 3 Ultra × ACE-RTL 领跑开源模型 agentic RTL 编码——Cadence / Synopsys / Siemens / ChipAgents / 三星 / Keysight / 台积电全线采用

NVIDIA 在 DAC 2026（7/26–29，长滩）宣布扩展面向工程的 Agent Toolkit，把重新架构的 PhysicsNeMo 库与更新版 CUDA-X 库作为"agent-ready 工具与技能"纳入，让开发者构建具备 AI 物理推理、加速求解与量子化学能力的自主 AI 工程师，覆盖芯片设计、验证、封装与系统。
① CUDA-X 新增 / 更新求解器：cuISS（CUDA 迭代稀疏求解器）加速大型稀疏线性系统；cuDSS（CUDA 直接稀疏求解器）明确服务于 EDA——加速器件 / 电路 / 系统仿真中的大型复杂稀疏线性系统，提供高性能 + 数值鲁棒性，支持多 GPU、多节点生产部署；cuEST（CUDA 电子结构理论）把高精度 DFT / 后 DFT 量子化学引入器件尺度。
② Nemotron 3 Ultra × ACE-RTL：NVIDIA Research 的 ACE-RTL 智能体在 Verilog 设计问题综合基准（RTL 编码任务）上领跑所有开源模型；Nemotron 3 Ultra 可基于专有数据后训练、本地 / 本地化部署，企业可控可定制、数据隐私更强；开发者可通过 Cadence / Synopsys / Siemens 工具套件或 Hugging Face 使用。
③ Vera CPU 加速验证：Cadence Jasper（形式验证平台）与 Synopsys VCS（高性能功能验证）正针对 NVIDIA Vera CPU（下一代 Arm CPU，Grace 继任）优化，提升先进芯片设计的验证吞吐量。
④ 生态采用与量化收益：Cadence AuraStack + Millennium M2000 基于 cuDSS，多物理场仿真最高 20×；Siemens Solido 库特征化速度 >10×、Token 成本降 >10×；三星 cuLitho 计算光刻最高 20× + PhysicsNeMo 百亿网格芯片级热应力分析（求解器级精度）；Keysight cuDSS 电磁仿真最高 10×；三星 / Synopsys / 台积电 cuEST 关键量子化学负载最高 50×；ChipAgents 用 Agent Toolkit 微调 Nemotron 构建芯片设计 / 验证领域智能体。
核心看点：这是本站 06-xx 已跟踪"NVIDIA Agent Toolkit 首发（NemoClaw / Nemotron 3 Ultra / OpenShell）"的重大扩展版——把 cuDSS 直接点名为 EDA 加速求解器、把 ACE-RTL 作为开源 RTL 编码 SOTA、并把 Vera CPU 拉入 EDA 验证加速，成为 Cadence / Synopsys / Siemens 三巨头 agentic EDA 共同的底层算力 + 模型底座。来源：nvidianews.nvidia.com、blogs.nvidia.cn。

ChipAgents · BusinessWire / Reuters / Yahoo Finance · 2026-07-29 · Series A2 +$60M → $134M（B Capital 领投，Micron / MediaTek / Ericsson / Bessemer 跟投）

💰 ChipAgents 追加 $60M Series A2、总盘子扩至 $134M——2026 上半年 ARR 增长 6×、部署超 120 家半导体公司（MediaTek / Micron），并深化 NVIDIA 合作开发芯片设计专用模型

ChipAgents（agentic AI 芯片设计平台）宣布追加 $60M Series A2 融资，使本轮总盘子扩至 $134M，距初始 A 轮仅六个月——反映其在半导体设计 / 验证领域 agentic AI 的商业势头。
① 融资结构：在 2025-10 $21M A 轮、2026-02 $50M A1 之后再获 $60M A2，10 个月内三轮；由新投资人 B Capital 领投，Micron、MediaTek、Ericsson、Bessemer 等现有投资人跟投；自 2024 年成立累计融资 $134M+。
② 商业化势头：2026 上半年 ARR 增长 6×，部署至 120+ 家半导体公司（含 MediaTek、Micron）；约 64 名员工，总部 Santa Clara，是行业最大的 agentic AI 芯片设计 / 验证商业部署之一。
③ 深化 NVIDIA 合作：本周扩大与 NVIDIA 战略合作，纳入开发 ChipAgents 芯片设计专用 AI 模型（专注 RTL / 验证）；CEO William Wang 拒绝对 NVIDIA 是否为投资人置评。
④ 平台能力：把规格 / 代码转化为生产就绪 RTL、验证资产与自动化根因分析（RCA），自主规划执行复杂设计 / 验证工作流，设计周期缩短 >50%；定位"自主执行"而非"辅助编码"的 copilot。
核心看点：与本站已跟踪的 ChipAgents $74M A 轮（首发）、Renoir 专用大模型、EY 年度企业家、×AWS 等构成完整商业化叙事；本轮最大亮点是战略投资人即客户（Micron / MediaTek 既出资又部署），且在 Cadence（收购 ChipStack）、Synopsys、Siemens 自研 agentic 工具夹击下，以"自主执行"定位 + 真实生产部署数据突围。来源：businesswire.com、reuters.com。
