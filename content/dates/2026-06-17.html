LLM4RTL: Tool-Assisted LLM for RTL Generation

作者：Jing Jin, Robert Chu, Ning Yan, Masood S. Mortazavi

提出 LLM4RTL，一种工具辅助的 LLM RTL 生成架构。核心贡献：(1) 提出 JRCRC（Judge-Renew-Check-Renew-Check）pipeline，利用分层商业 LLM（不同成本与能力）对公开数据集进行成本效益驱动的过滤和精炼，构建高质量训练数据集；(2) 识别出 LLM 在基于规则的推理和逻辑推断方面的常见弱点（尤其在 RTL 代码生成中），开发了一种 工具辅助架构，通过预处理工具动态辅助 LLM 从表格数据格式中推断逻辑关系。实验表明，LLM4RTL 在 VerilogEval 基准上取得显著整体性能提升，超越多个 SOTA 方法，并以显著更小的 LLM 达到与 GPT-4o 相当的性能。

arXiv:2606.15052 · cs.AR / cs.AI · 2026-06-13

PANDA: An LLM-Enhanced Performance-Driven Analog Design Framework Bridging Design Intent and Layout Generation

作者：Haoyi Zhang, Weijian Fan, Xiaohan Gao, Bingyang Liu, Runsheng Wang, Yibo Lin

提出 PANDA，一个 LLM 增强的性能驱动模拟电路设计框架，从高层设计意图直接桥接到最终布局。PANDA 通过引导式拓扑合成、子结构感知尺寸调整和约束驱动的布局生成，主动管理跨阶段依赖关系。这将自动化从"算法中心执行"转变为"意图中心协同设计"，将周转时间从数天/数周缩短至数小时，同时提升设计性能。来自北京大学林亦波团队。

🔧 eda-agent：开源 Altium Designer MCP 服务器 — 300+ 工具覆盖原理图/PCB/库全流程

开源项目 eda-agent 提供了一个 MCP 服务器，可在 AI（或任何 MCP 兼容客户端）与正在运行的 Altium Designer 会话之间建立实时交互通道。提供 300+ 工具，覆盖原理图（93 工具）、PCB（104 工具）、元件库（36 工具）、项目管理（53 工具）、设计代理（19 工具）和布线（2 工具）六大类。核心亮点包括：批量操作效率提升 10-100x、31 项设计审计检查、从 DesignPlan JSON 自动生成原理图/布局/网表、离线 A* 布线 + DRC 修复。通过 DelphiScript 桥接实现文件 IPC 通信，支持 10ms 活跃/100ms 空闲双模式轮询。最新提交修复 AD26 兼容性问题。这是 Agentic EDA 在 PCB 设计领域的重要开源实践。
