⚡ SeqFeed：用「顺序行为反馈」提升智能体 RTL 代码生成——SeQuery（类 SQL 波形查询语言）+ SeGraph（跨周期信号依赖图），事件可寻址 / 依赖可追溯 / 可迭代查询

RTL 代码生成是硬件设计的关键环节，而智能体系统为自动化这一过程带来新机遇；要生成正确的 RTL，智能体必须理解顺序行为——信号如何随多个时钟周期演化与传播。然而，如何把这类时序信息有效传递给智能体仍是重大挑战：RTL 代码并不暴露某次执行的周期级信号行为，而完整仿真波形又过于庞杂、噪声过多，难以被 LLM 有效分析。受人类工程师推理顺序行为的启发，本文提炼出有效反馈的三大要求：事件可寻址（event-addressable）、依赖可追溯（dependency-traceable）、可迭代查询（iteratively-queryable）。据此提出 SeqFeed，含两个互补机制：① SeQuery，一种类 SQL 的波形查询语言，让智能体把查询锚定到语义事件、并在相对时间点采样信号值；② SeGraph，一个跨时钟周期追踪信号传播的依赖图。在多个 LLM 上的实验表明，SeQuery 与 SeGraph 各自有效、且结合后提供互补增益，显著提升 pass rate。对「LLM 结合智慧体协作的 RTL 生成-验证-反馈闭环」是直接方法论补充。

🔬 NeuroAbs：神经符号 RTL 抽象框架加速属性检查——LLM 辅助识别可抽象信号 + AST 符号表示对齐 + SMT 检查 + CEGAR 迭代细化（ICCAD 2026）

形式验证是确保硬件设计功能正确性的关键技术；在属性检查（property checking）中，如何面对日益复杂的 RTL 设计高效证明用户指定属性是一大挑战。抽象（abstraction）技术常被用来降低系统复杂度、加速验证，但既有 RTL 抽象方法要么需大量人工、要么依赖缺乏灵活性的基于规则的技术。NeuroAbs 提出一个神经符号（neuro-symbolic）RTL 抽象框架：首先用 LLM 辅助的 RTL 分析识别适合抽象的信号；随后将 LLM 生成的抽象与基于 AST 的符号化 RTL 表示结合，使生成的抽象更贴合预期变换；每一处抽象的可靠性（soundness）用可满足性模理论（SMT）求解检查；若抽象过粗导致证明失败，则应用反例引导的抽象细化（CEGAR）迭代精化模型。实验表明，NeuroAbs 在一系列验证任务中显著提升了硬件属性检查的效率。作者含香港科技大学（HKUST）Hongce Zhang 组，属 ICCAD 2026 正式论文，对「LLM 辅助形式验证 / RTL 抽象 / 验证反馈闭环」是高信号工作。

🌡️ DeepOHeat-v2：3D-IC 热优化的自改进算子学习——不连续传导率能量形式 + 热点信任门 + 增量重训，56× 加速、峰值温差 0.11K

多芯粒（multi-die）3D 集成的热感知优化需评估大量设计，每个都是昂贵的传热方程求解。算子学习代理用快速前向传播替代该求解，理想情况下仅从物理训练、无需标注数据。DeepOHeat-v1 已使代理快速可信，但仅适用于低对比度几何；高对比度多芯粒堆叠从两方面击穿它：不连续传导率在材料界面使连续物理损失无定义，病态条件（κ²≈6×10⁴）使离散强形式损失超出一阶优化范围。DeepOHeat-v2 克服两者：①在原生处理不连续的离散化物理损失上训练，其能量形式把预测空间损失-Hessian 条件数从 κ² 降到 κ，矩阵预条件优化器把平均峰值温度误差从 30K+ 降到 0.55K；②因优化会离开训练分布，提出自改进框架——热点信任门把被标记的布局送参考求解器，代理在精化解上增量重训，仅当改善留出验证误差时保留更新。多芯粒基准上，返回设计的代理-真值峰值温差从 1.12K 降到 0.11K，匹敌逐步求解优化器且快 56×。属「Chiplet/3D-IC 多物理场 AI 热分析」的高信号工作。

📡 The Road Less Traveled：FPGA NoC 感知拥塞布局与包路由——VPR 注入链路拥塞代价 + turn model + SAT 求解，拥塞降 95.1%

现代 FPGA 集成片上网络（NoC）以传输高带宽数据，但 NoC 给 CAD 流程引入新约束与度量：布局布线需优化 NoC 时延/带宽利用率并避免链路过订阅（拥塞），同时优化挂接 NoC 路由器的模块的可编程布线资源。本文：①把 NoC 链路拥塞代价注入开源 CAD 流程 VPR 的布局引擎；②把 turn model NoC 路由算法集成进布局引擎以利用路径多样性进一步降拥塞；在 29 个基准上，布局拥塞建模 + turn model 包路由平均降 NoC 拥塞 90.7%（聚合带宽需求仅 +4%）；对仍无法完全解决拥塞的情形，把 NoC 路由建模为布尔可满足（SAT）问题，组合算法相对基线布局降拥塞 95.1%；③还增强 VPR 布局引擎的强化学习（RL）智能体，引入 NoC 感知 move 类型，在大量使用 NoC 的设计上线长降 8.8%。属「FPGA CAD / 物理设计 + RL + 拥塞优化」方向。

⏱️ 开源 IC 设计中的轻量级预布线延迟估计——决策树 + 线性回归混合模型，较 OpenLane 误差降 80%，体积小 300×

静态时序分析（STA）是数字 IC 设计流程的关键步骤，但在物理设计信息有限时获取准确延迟估计仍是挑战。本文提出一种混合轻量机器学习方法，把决策树与线性回归结合，改善开源 RTL-to-GDSII 工具 OpenLane 生成的预布线延迟估计：相对 OpenLane 估计误差降 80%，即便不使用 OpenLane 专属参数也改善 71%；该方法比传统延迟传播技术与更复杂的 ML 模型更准确，且体积小 300 倍以上、速度快 2×、可解释性更高。属「开源 EDA（OpenLane）+ 时序估计 ML」的实用型工作，对布线前早期时序预估有直接的工程价值。
