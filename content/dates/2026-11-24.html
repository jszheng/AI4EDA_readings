🤝 ChipAgents 扩大 Renesas 全球采用：agentic AI 平台覆盖日本 / 美国 / 欧洲 / 印度工程团队，下一阶段聚焦 PPA 优化 RTL 收敛与模拟设计，并扩充全球 FDE 团队

芯片设计智能体平台厂商 ChipAgents 于 11 月 23 日宣布，瑞萨电子（Renesas Electronics）正扩大对 ChipAgents 平台的采用，覆盖其日本、美国、欧洲与印度的工程团队——这是瑞萨把 AI 原生能力融入半导体设计与开发的重要一步。要点：① 此次扩展建立在设计与验证环节一系列成功的工程评估之上，评估显示该平台能在保持芯片开发所需准确性、透明度与严谨性的前提下加速工程任务，为在全球运营中更广泛部署奠定基础；② ChipAgents 创始人兼 CEO William Wang 表示，AI 原生芯片设计意味着把设计意图连接到经过验证的结果、并让 AI 扎根于硅的物理约束，瑞萨的扩大采用是迈向该愿景的重要一步，双方将把数字与模拟工作流带入统一方法——工程师设定方向，AI 智能体执行、从结果中学习并加速开发；瑞萨工程副总裁 Manoher Bommena 指出，让智能体承担更多常规设计与验证任务，可在保持半导体开发质量要求的同时显著提升工程生产力；③ 平台核心为芯片神经引擎 IC-star，融合物理感知模型、组织工程知识与自演化智能体工作流，把 AI 推理、规划、执行与物理反馈相连，在实现更高自动化的同时让工程师掌握目标与关键决策；④ 为支持瑞萨的全球采用，ChipAgents 正扩充其全球「前置部署工程」（FDE）组织，提供专属专业能力、工作流集成、区域上手与本地语言培训；⑤ 下一阶段合作将把智能体 AI 引入两个关键领域——PPA 优化的 RTL 收敛（PPA-optimized RTL closure）与模拟设计。ChipAgents 2024 年成立，总部位于美国加州圣克拉拉。此为厂商合作扩展 / 平台采用类行业动态（与已收录的 ChipAgents 融资、Andes×ChipAgents、Rambus 采用、Cognichip 客户含瑞萨等均为不同事件），非 arXiv 论文通知 / 学术征稿。

⚙️ 新禹思 HyperS2C 推出「编译 + 调试」双 EDA 智能体 HSCompile.aix：编译优化耗时缩短 50%~80%，并与华大九天探索跨工具 Super Agent

腾讯新闻 11 月 24 日报道，由亚科鸿禹与思尔芯合并重组、获华大九天等 5 亿元增资的数字前端 EDA 厂商新禹思（HyperS2C），正以 AI Agent 降低工具使用门槛并推出面向编译环节的 HSCompile.aix。要点：① 数字前端 EDA 的编译过程高度依赖工程师经验——编译策略、资源分配与参数配置都会影响结果，工程师往往需反复尝试；新禹思希望借 AI Agent 让普通设计工程师也能完成过去需要资深工程师处理的任务，为此基于公司 20 余年积累的工程经验、产品文档、设计测试案例与客户项目数据开发了 HSCompile.aix，辅助工程师完成编译与优化；② 效果上，过去一名工程师通常只能负责一两个项目，借助 Agent 可同时尝试不同 SoC 架构与编译方案，有机会管理四五个项目；在部分编译优化任务中，AI 可把相关时间缩短 50%，甚至 70%~80%；③ 调试是 AI Agent 的另一重要方向——现代 SoC 验证会产生大量波形、信号、日志与仿真比对数据，出问题后工程师需从海量信息中定位异常并分析根因；新禹思希望用 AI Agent 自动分析这些数据、帮助定位问题并给出可复现、可验证的证据，相关 AI 工具已在客户项目中使用（早期由应用工程师辅助客户，部分能力已产品化）；④ 从单 Agent 走向 Super Agent：一颗芯片从架构、RTL、验证到综合与布局布线需用到大量 EDA 工具，各自 I/O 格式、脚本接口与操作方式不同，即便每款工具都有独立 Agent 也难以自动贯通全流程；新禹思与华大九天正探索跨工具 AI 协作——由 Super Agent 根据设计目标调用不同 EDA 工具、分析各阶段结果并持续优化方案；⑤ 对「AI 取代 EDA 工程师」，创始人林俊雄表示目标不是取代，而是让工程师「以前做一件事、现在做十件事」，完全让 Agent 自主判断结果可能还需数年，现阶段仍需工程师检查与确认最终结果。此为国产 EDA 厂商 AI Agent 产品发布 / 合作探索类行业动态（与 11-13 收录的「合并重组 + 5 亿融资」属不同事件），非 arXiv 论文通知 / 学术征稿。

🧩 Bridging the Semantic Gap from Natural Language Specifications to RTL with Layered Formal Guidance——以分层形式化引导弥合自然语言规格到 RTL 的语义鸿沟

LLM 从自然语言规格生成 RTL 在复杂控制逻辑与时序行为设计上可靠性有限，根源在于高层自然语言常遗漏实现关键细节，迫使 LLM 推断未言明的假设。本文提出 Layered Formal Guidance，把形式化属性作为自然语言规格与 RTL 生成之间的中间语义层，分三层施加引导：生成前的属性驱动规格增补、生成后的属性一致性检查、检查后的反例引导精化。在 RTLLM 基准与多种开源 IP 设计上，框架取得更高的功能正确率与更低的采样输出轨迹多样性；并可灵活增强通用 LLM 与领域专用模型，显著提升生成可靠性。属「前端 RTL / 形式化引导的规格到 RTL 生成（属性中间层 + 一致性检查 + 反例精化）」方向。

🔎 ChiProgramBench: Can LLM Agents Rebuild Efficient Circuits from Pin-Level Experiments?——LLM 智能体能否仅凭引脚实验重建高效电路？

为评估 LLM 智能体理解「可运行但不可检视」硬件系统的能力，本文提出 ChiProgramBench：18 个任务源自开源处理器、加速器、编解码器、变换、互连与控制电路。智能体只能驱动并读取隐藏有状态仿真参考的引脚，随后提交由公开库单元构成的门级网表；黑盒发现设置仅提供匿名功能引脚与固定存储器接口，功能引导重建则额外给出电路用途与各引脚角色。隐藏测试逐周期比对输出，且仅在全部用例通过时，功耗、延迟与面积才按相对参考的表现计分。在 6 种智能体配置、432 次试验中，黑盒与功能引导的全用例通过率仅 12.0% 与 14.8%；功能引导把平均功能分（按周期加权的通过用例占比）从 24.6% 提升到 30.9%；58 个全通过设计中仅 3 个在功耗、面积、延迟综合上优于参考——行为恢复与高效实现仍是两项独立挑战。属「AI Agent / 硬件黑盒逆向重建基准（引脚实验 + 假设验证 + 门级网表 + PPA 计分）」方向。

⚙️ LLM-Assisted Co-Optimization of RTL and Synthesis Algorithms via Bottleneck Analysis——基于瓶颈分析的 RTL 与综合算法 LLM 辅助协同优化

综合后 PPA 由 RTL 代码与综合算法共同决定：只优化任一层，收益都可能被另一层的瓶颈限制。本文提出 LLM 辅助的区域协同优化框架——RTL 结构与综合所用布尔网络对电路不同区域的瓶颈暴露互补机会；高斯过程（GP）从区域图表示与 PPA 反馈中学习，判断每个区域优化 RTL 还是综合算法更有潜力；贝叶斯优化结合 GP 预测与预测不确定性给出指导，LLM Router 再结合电路分析选择各区域的处理方式；自我改进的 LLM worker 分别优化 RTL 或综合算法，并把区域改动贪心集成进当前设计配置。在 16 个 RTL 设计上，WNS 平均改善 103.27%、面积 1.23%、功耗 13.26%，相对各指标最强基线分别高出 47.80、2.75 与 13.17 个百分点。属「前端 RTL / LLM 驱动的 RTL 与综合算法协同优化（瓶颈分析 + GP/BO 决策 + 区域贪心集成）」方向。

📉 Multi-Order Passive Macromodeling from Layouts via Nested Port-Hamiltonian Learning——基于嵌套端口-哈密顿学习的版图多阶无源宏建模

互连与电源分配网络的紧凑无源状态空间宏模型，是稳定开展信号/电源完整性瞬态仿真的重要基础；但传统流程需对每个版图做昂贵的全波 EM 仿真，而传统拟合与已有学习代理多依赖事后拟合或无源扰动，精度受损且不保证收敛。本文提出直接在无源空间中学习的端到端宏建模框架，把物理版图图映射为多阶端口-哈密顿（pH）宏模型：网络把版图图编码为无约束矩阵块，再以完备的前缀嵌套 pH 参数化组装，从构造上保证连续频域的无源性与稳定性，一次前向传播经状态切片即可得到任意 k 阶模型；训练时用渐进阶数增长课程直接以 S 参数监督所有阶次，无需参考实现。在先进封装 27 万结构数据集中 2.7 万个未见测试结构上，平均 S 参数误差较基于真值 EM 响应拟合的主流工具降低 42%（最高 65%），导出的 459,000 个模型零无源违例，宏模型生成加速 11,000–39,000×（每版图 36–85 ms）。属「模拟与架构 / 版图到无源宏模型的端到端学习（pH 参数化无源保证 + 阶数增长课程 + 大规模加速）」方向。
