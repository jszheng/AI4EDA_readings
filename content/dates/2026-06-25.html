🐛 VeriPilot：LLM 驱动的 Verilog 调试框架 — 黄金参考模型 + CDFG 实现 Bug 自动定位与修复

提出VeriPilot，一个基于 LLM 的 Verilog 调试框架。核心创新：(1) 利用黄金参考模型（如 C 模型）生成期望行为，通过对比仿真输出定位 Bug；(2) 构建控制数据流图（CDFG）缩小错误搜索空间，将 Bug 定位到具体信号和代码行；(3) LLM 基于精确定位信息生成针对性修复补丁。在 NVIDIA CVDP 基准上评估：将 GPT-4o 修复成功率从 54.3% 提升至 85.71%，平均调试时间减少62%。框架支持多种 LLM 后端，开源 GitHub：YihanWn/VeriPilot。
核心创新：黄金参考模型对比 + CDFG Bug 定位 + LLM 精确定向修复 + 85.71% 成功率

🖥️ PCB-QA：首个 PCB 设计 QA 数据集 — 480 对问答 + 8 个开源硬件项目，评估 LLM 电路设计理解

提出PCB-QA，首个面向PCB 设计领域的大语言模型问答评测数据集。核心贡献：(1) 从 8 个开源硬件项目中提取 480 对问答，覆盖原理图理解、布局规则、元器件选型、信号完整性等真实 PCB 设计场景；(2) 系统评估 GPT-4o、Claude、Gemini 3 Flash Preview 等主流 LLM 的电路设计理解能力；(3) Gemini 3 Flash Preview 达到 93% 准确率，揭示 LLM 在硬件设计自动化方面的巨大潜力。数据集和评测框架开源，为 EDA 领域 LLM 基准测试提供新维度。
核心创新：首个 PCB 设计 QA 数据集 + 480 对真实问答 + Gemini 3 Flash Preview 93% 准确率
