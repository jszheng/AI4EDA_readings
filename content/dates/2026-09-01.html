🤖 Gen-TAS：知识锚定 LLM+RAG 的 FPGA-GPP 任务分配框架——人机协同 + 确定性后端生成可复现 FPGA SoC，相对全 GPP 最高 92.53× 加速

FPGA-GPP 异构系统兼顾软件灵活性与可重构硬件的性能/能效，但决定哪些应用任务跑在 GPP 或 FPGA 上需要大量专家经验与设计空间探索，尤其当用户目标在时延、通信、资源占用与功耗之间权衡时。本文提出 Gen-TAS，一个面向用户特定 FPGA-GPP 任务分配的知识锚定 LLM 框架：将任务图分析与 RAG 结合，使 LLM 推理锚定在历史实现知识上，生成多个可解释、贴合指定目标的策略；再通过人机协同选择（human-in-the-loop）与确定性后端，把 LLM 决策连接到可复现的 FPGA SoC 实现。在 CNN 与 SDR 负载、多个 LLM 上的实验显示稳定、需求驱动的分配；在时延导向目标下，所选策略相对对应全 GPP 基线分别取得最高 2.45× 与 92.53× 加速，其他目标则在 FPGA-GPP 通信、资源占用或 FPGA 功耗之间做权衡。属「AI Agent / 异构系统任务分配」方向，是把 LLM+RAG 用于 FPGA 系统级设计空间探索的代表工作，对 AI 辅助硬件-软件协同设计与可复现 EDA 流程有直接支撑。

🔬 AI Hardware Accelerators for LLMs：GPU/ASIC/FPGA/PIM/神经形态/光子加速器综述——以 roofline 指出 LLM 加速瓶颈是内存墙而非算力

大语言模型（LLM）对训练与部署硬件提出空前且持续增长的需求。本综述梳理 LLM AI 硬件加速器的全貌：通用 GPU、TPU/Trainium/Groq/Cerebras 等定制 ASIC、可重构 FPGA、存内/近存计算（PIM），以及新兴的神经形态与光子路线，覆盖云与边缘部署。以 transformer 计算结构与 roofline 分析 为统一框架，作者指出 LLM 加速的决定性约束不是算术而是内存：自回归解码阶段受带宽限制、KV 缓存规模可媲美模型权重、数据搬运主导能耗。在算力、内存、能耗、可编程性与可扩展性上比较各平台后得出结论：不存在跨负载最优的单一架构——GPU 仍是灵活默认与训练主力；领域专用 ASIC 在稳定大批量负载上胜出；PIM 是对内存墙最有前景的近期应对、作为异构补充进入系统；神经形态与光子虽有前景但尚未在前沿规模量产就绪。未来进展依赖硬件-算法协同设计与以内存为中心的异构系统：对 LLM 而言，内存系统已成为计算机本身。属「模拟与架构 / 硬件加速器」方向的权威综述，对理解 AI 加速器格局与内存墙瓶颈有直接参考价值，亦为 PIM/近存用于 EDA 大模型的底层算力提供背景。

⚡ SeCRTLGen：LLM-RTL 生成的「隐式安全义务」盲区基准——SECRTL-GEN（392 任务 × 5 CWE × 4 HDL）+ 神经符号 RTL-Obliger 把全通过率从 ~50% 提到 61.6%

大语言模型（LLM）生成寄存器传输级（RTL）代码的功能正确性快速提升，但 LLM 生成代码的安全性研究多集中在软件（部署后仍可打补丁）；一旦流片进硅，不安全的 RTL 没有补救机会。本文构建 SECRTL-GEN——一个扎根真实 SoC IP 的多语言资源访问安全基准：392 个任务覆盖 5 个 CWE 族与 4 种 HDL（Verilog、SystemVerilog、VHDL、Python），每个任务都配有黑盒功能与安全测试平台；功能规格刻意省略安全义务，复现现实中安全义务常被排除在功能文档之外的情形。对 5 个前沿 LLM 的实证显示明显鸿沟：朴素提示下功能测试通过率约 73–79%，安全测试仅 14–35%，且功能更强的模型并不更安全。加入 CWE 知识能提升安全性，而无辅助的自发思考帮助有限，两种安全导向提示都会降低功能通过率——说明瓶颈在于规格中缺失弱点意识，而非写不出防御性 RTL。作者提出 RTL-Obliger，一个神经-符号框架推断这些隐式义务：LLM 从规格抽取功能-语义图，符号引擎对照 CWE 模式本体匹配以暴露缓解-证据缺口与信号级义务，LLM 最终在这些义务下以「功能保持的两阶段生成」修订 RTL。在 5 个模型、4 种语言上，RTL-Obliger 将平均全通过率从 49.6–51.4%（SecV/RESCUE）提升到 61.6%，安全与功能通过率均高于这些安全生成基线。属「前端 RTL / RTL 生成安全」方向，揭示 LLM-RTL 生成的隐式安全义务盲区并给出血肉兼修的神经-符号缓解，与 RTLGuard（2608.26049）的后门防御形成「生成安全 + 检测安全」互补。

📐 DeepSeq3：超越扁平网表的分层图表示学习——组合子图 + 寄存器传输超图（SNG）双 GNN 建模时序电路，BMC 求解时间降 18%

电路表示学习（CRL）为引导和优化核心 EDA 任务提供强有力范式，但其实际落地受工业级网表巨大规模与未能显式建模寄存器级时间动态所阻碍。为突破这些障碍，本文提出 DeepSeq3，一个把电路抽象为两级表示的分层框架：由触发器（FF）划分的细粒度组合子图，以及建模寄存器传输结构的高层超级节点图（SNG）。双 GNN 架构在两级分别学习表示，捕获局部布尔逻辑与全局状态转移；关键在于引入以状态为中心的预训练方案，预测 FF 状态间可达性，赋予模型对时间行为的深层理解。在大规模基准上，DeepSeq3 取得更优的可扩展性与更丰富的表示，在保障正确性的同时将限界模型检测（BMC）求解时间降低 18%。属「物理设计 / 电路表示学习」方向，用「组合子图 + 寄存器传输超图」的分层 CRL 显式建模时序动态，直接服务 BMC 等大规模电路分析，与 GNN 用于布局/时序预测的工作形成方法互补。
