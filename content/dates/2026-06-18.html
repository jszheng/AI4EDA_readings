AUTOGATE: Automated Clock Gating via Toggling-Aware LLM-based RTL Rewriting

作者：Yiting Wang, Chenhui Deng, Chia-Tung Ho, Yanqing Zhang, Zhuo Feng, Cunxi Yu, Ang Li, Gang Qu, Brucek Khailany

首个面向工业级 RTL 功耗优化的Agentic 框架，实现负载感知的自动时钟门控。AUTOGATE 提出 ML-LLM 协同设计：ML 聚类算法将原始波形翻转轨迹蒸馏为紧凑结构化表示，引导 LLM 进行 RTL 重写——避免 LLM 直接处理原始波形数据的瓶颈。采用分层多智能体架构，将大型设计分解为独立可优化模块，实现深层设计层次间的协调优化。小设计套件平均动态功耗降低 49.31%；NVDLA 降低 19.34%，BlackParrot 降低 7.96%，高度优化的量产设计降低最高 6.86%。

PDAGENT-BENCH: Characterizing, Grounding, and Architecting LLM Agents for VLSI Physical Design

作者：Qiufeng Li, Rongqian Chen, Quan Cheng, Chengxuan Wang, Sizhe Tang, Wuxi Li, Duo Ding, Chia-Tung Ho, Haoxing Ren, David Z. Pan, Tian Lan, Weidong Cao

首个全面、多维度的LLM/VLM 智能体物理设计基准。PDAGENT-BENCH 包含 353 个精选问题，覆盖五大能力维度：基础知识、报告理解、根因分析、脚本生成、全流程实现。对 11 个 SOTA 模型评测发现：LLM/VLM 在概念任务上表现竞争力，但在工具中心执行方面仍然严重受限（Innovus 脚本生成仅 42.2%），长时距多阶段推理能力不足。研究表明人类技能增强的智能体工作流显著提升端到端物理设计性能。基准和框架即将开源。

Shift-Left High-Level Synthesis Verification via Knowledge-Augmented LLM Agent

作者：Zhihan Xiao, Zhe Zhao, Luke Ztz Hu, Songping Mai

提出知识增强、智能体驱动的左移验证框架，在综合前自动检查 golden C 与 HLS-C 实现间的功能一致性。引入 双层一致性检查机制（静态结构对齐 + 动态行为等价），结合符号执行和覆盖率驱动精炼提升验证完整性。构建异构 HLS 验证知识图谱提供拓扑感知推理先验，设计自主验证智能体协调迭代精炼和故障诊断。107 个 HLS 基准对上平均覆盖率 98.26%，动态一致性 95.33%，显著超越 AST-based、RAG 和迭代 Agent 基线。GitHub: cz-5f/HLS-LeVeri

CUTh-Solver: GPU-Accelerated Sparse Matrix Solver for High-Resolution Thermal Simulation of 3D ICs

作者：Chenghan Wang, Zhen Zhuang, Shui Jiang, Siyuan Liang, Xiaoman Yang, Kai Zhu, Darong Huang, Luis Costero, Rongmei Chen, Tsung-Wei Huang, David Atienza, Tsung-Yi Ho

提出面向3D IC 高分辨率稳态和瞬态热仿真的协同设计 GPU 加速 PCG 稀疏求解器框架。核心优化：(1) 浓缩 DIA 存储格式去除冗余；(2) 对角线 SpMV 实现合并内存访问；(3) 高并行化预处理策略；(4) 自适应细粒度混合精度策略避免资源竞争。实验表明 CUTh-Solver 相比 GPU 加速的 COMSOL Multiphysics 6.4 达到最高 25.8x 加速，相比 NVIDIA 原生通用库（AmgX/cuSPARSE/cuDSS）加速超过 3x。代码开源：GitHub

ComPart: Community-Guided Post-Coarsening for High-Quality Hypergraph Partitioning

作者：Yugao Zhu, Zhicheng Guo, Yuchao Wu, Mengming Li, Jing Wang, Zhiyao Xie

提出将多种社区检测方法集成到后粗化阶段（初始划分和去粗化）的通用超图划分框架。发现社区结构在去粗化阶段可帮助逃离局部最优、探索全局有意义的解空间子域。首次将局部密集分解从图域严格推广到超图域，用于引导初始划分获得更优起点。实验在标准基准上持续超越 SOTA 方法。DAC 2026 接收。

IMPart: Integration of Memetic Operations into Multi-Level Framework for Large-k-Way Hypergraph Partitioning

作者：Yugao Zhu, Zhicheng Guo, Shang Liu, Mengming Li, Jing Wang, Zhiyao Xie

将模因操作（重组和突变）直接集成到多级框架的去粗化阶段，而非像传统方法那样调用独立多级划分器。这使得不同粒度的局部搜索转变为协作搜索，有效逃离局部最优并探索全局解空间。在大 k-way 超图划分问题上大幅超越所有现有超图划分器，为先进划分器开发提出新范式。
