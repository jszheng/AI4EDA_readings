VHDLSuite: Unified Pipeline for LLM VHDL Generation with Data Synthesis and Evaluation

作者：Yijun Shen, Minghao Shao, Yichen Zhao, Zhuoyan Yu, Boyuan Chen, Yik-Cheung Tam, Muhammad Shafique

提出 VHDLSuite，一个以基准测试为核心的、可扩展的 VHDL 生成评估基础设施。首先，提出一条自动化数据 pipeline，可将 Verilog 设计及其配套的测试平台转换为可执行的 VHDL 基准实例，通过 VUnit/GHDL 完成验证，确保每个任务在 VHDL 环境中可编译、可运行、可一致性检查。其次，提出 VHDLBench 基准测试集，包含 200+ 覆盖不同复杂度级别的、带有完整且经过验证的测试平台的 VHDL 问题。第三，对前沿 LLM 进行广泛评估，揭示了 LLM 辅助 VHDL 生成特有的关键挑战。数据 pipeline、基准测试集和评估框架将开源。

RTL生成 VHDL 基准测试 数据合成 LLM评估

arXiv:2606.13706 · cs.AR / cs.AI · 2026-06-09

HierSVA: A Data Synthesis Pipeline, Dataset, and Benchmark for LLM-Driven Hierarchical Hardware Formal Verification

作者：Maohua Nie, Jiang Zhu, Jingqun Zhang, Zhichen Zeng, Jiayi Wang, Sibo Zhang, Jialin Wang, C.-J. Richard Shi

提出 HierSVA，一套为 LLM 驱动的分层硬件形式化验证设计的集成套件。HierSVA-SP 整合了 RTL 预处理工具链和 LLM 参与的形式化验证流程，可生成分层 RTL 的参考 SystemVerilog 断言（SVA）。应用于 BaseJump STL 标准库后得到 HierSVA-DS 数据集（342 个模块，0-9 层级深度，含 28 组模块-缺陷对）。HierSVA-B 将断言质量拆解为 6 个度量维度：语法正确性、断言证明成功率、空断言率、规格符合度、突变覆盖率和形式化核心覆盖率。对 12 个近期 LLM 评测发现：模块级编译率 67.1%，非空断言 82.1% 可证明但仅检测 70.2% 的注入故障；缺陷检测召回率 0.87 但精确率仅 0.60（误报率 40%）；Agent 模式提升可证明性但存在平台期。

功能验证 形式化验证 SVA生成 LLM 基准测试

arXiv:2606.13747 · cs.AR / cs.LG · 2026-06-11

BigPower: Hierarchical Source-Level Module Power Estimation for CPUs with Large Language Models

作者：Honghua Zhu, Chunjie Luo, Jianfeng Zhan

提出 BigPower，一种用于 CPU 设计阶段细粒度模块级功耗估计的分层源码级替代模型。BigPower 利用基于大语言模型的表征，结合架构层次、模块连接性、配置参数和工作负载上下文，可直接从源码级设计信息估计模块级功耗，推理阶段无需额外仿真。在开源香山处理器家族上的实验表明，该方法可在不同配置和工作负载下实现实用的细粒度功耗估计，为传统基于仿真的流程提供了高效替代方案。

功耗估计 LLM表征 CPU设计 香山处理器 源码级分析

🛡️ NVIDIA 开源 SkillSpector：AI Agent 技能安全扫描器 — 26.1% 公开技能含漏洞

NVIDIA 发布开源安全扫描工具 SkillSpector，用于在安装 AI Agent 技能（Claude Code、Codex CLI、Gemini CLI 等）前检测漏洞、恶意模式和安全风险。研究发现 26.1% 的公开技能包含漏洞，5.2% 显示可能恶意行为。SkillSpector 通过 64 种漏洞模式检测 + 可选 LLM 深度分析，支持集成到 CI/CD 流程。这对构建 EDA AI Agent 技能生态具有重要意义——随着 Agentic EDA 工具链（Siemens Fuse EDA、Cadence ChipStack 等）的技能化趋势加速，安全扫描成为必要基础设施。GitHub: nvidia/skillspector
