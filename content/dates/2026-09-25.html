⚡ RTLReview-Agent：多智能体 RTL 生成后审查闭环——自动审查生成 RTL 的设计缺陷、可维护性与规格漂移，把「生成-审查」做成可追责的质量闸门

LLM 生成 RTL 的「生成-验证闭环」里，审查（review）长期被弱化为「仿真过了就行」，而真实工程里更多返工来自设计缺陷、可维护性差、规格漂移这类仿真不报错但后续会爆雷的问题。RTLReview-Agent 在生成之后接一道生成后审查闭环：① Defect-Reviewer（缺陷审查器）用静态分析 + LLM 对照契约检查死代码/锁存推断/异步复位缺失等可综合陷阱；② Maintain-Reviewer（可维护性审查器）评估模块耦合度、命名与接口一致性、可测试性，给出可执行的重构建议；③ Drift-Reviewer（漂移审查器）把生成 RTL 与原始规格做双向 diff，标出「代码变了但规格没跟上」的漂移点。三者结论汇总成一份可追溯审查报告，未通过阈值的 RTL 退回到生成器重做。在 RTLLM v2.1 与 VerilogEval 子集上，相对「仅仿真」基线，下游首次流片级返工降 41%、代码评审人工工时降 58%。属「前端 RTL / 智慧体协作的 RTL 生成-验证-反馈闭环」方向，把此前 Spec2RTL-Agent（2609.11342）、VeriRAG（2609.14102）、RTLRepair-Agent（2609.14910）聚焦的「生成-修复」补上最缺失的「生成后审查」质量闸门，使闭环从「能跑」升级到「可维护、可追溯」。

📐 DRVRepair-RL：强化学习驱动设计规则违例（DRV）自动修复——把 DRC 违例聚类为可学习的布局后修复策略，详细布线违例降 29%

布局后优化（post-placement optimization）里，设计规则违例（DRV）——最小面积、最小间距、阱连接、天线效应等——往往在详细布线阶段才集中爆发，而此时回改布局代价高昂。DRVRepair-RL 把 DRV 修复建模为序列决策：强化学习智能体在布局后图上逐簇处理违例，动作空间覆盖单元微移、well-tap 插入、填充单元（filler）布局、天线二极管插入，状态编码融合局部密度、违例类型分布与拥塞图；奖励函数把违例计数与可布线性惩罚联合加权，并引入违例聚类引导——先把同类违例聚成可批量修复的「修复单元」，再让 RL 学出该簇的最优修复组合，避免逐条修引入新违例。在 ISPD/TCAD 基准与开源 OpenROAD 流程上，相对商业 PPO + 逐条修复基线，详细布线 DRV 总数降 29%、修复迭代轮次降 36%、面积增仅 1.4%。属「后端物理设计 / 强化学习在单元大小调整、缓冲器插入、布局后优化的应用」方向，把此前 BufFormer（2609.14357）的 RL 联合决策扩展到「DRV 自动修复」这一最琐碎也最烧人力的工序，与本站关注的「RL 在布局布线」细分一致。

🌡️ ChipletThermalGNN：GNN 驱动多芯粒系统热分布与互连拥塞协同预测——在封装图上学热-拥塞耦合，秒级给出热感知互连规划

多芯粒（Chiplet）系统里热分布与互连拥塞深度耦合：高带宽 Die-to-Die 链路堆叠即热点，而热约束又反过来限制互连摆放与供电。现有做法把热场与互连拥塞当作两个串行工具求解，每次迭代动辄分钟级。ChipletThermalGNN 把多芯粒系统建模为封装异构图（芯粒/微凸点/TMV/中介层为节点，互连带宽与热阻耦合为边），用图神经网络在图上同时回归稳态/瞬态温度场与互连拥塞图，并引入热-拥塞耦合物理残差正则（热流守恒 + 带宽守恒 + 热致时延一致性）约束预测满足物理律；推理秒级输出「互连规划→热分布」联合解，并给出可微分梯度提示（把高功耗、高带宽芯粒错开放置）。在 2.5D/3D 开源 Chiplet 基准上与商业有限元/互连规划工具对齐，峰值温度 RMSE < 2.0°C、拥塞预测 F1 0.93，下游协同优化使峰值温度降 6.5%、关键链路延迟降 10%。属「后端物理设计 / Chiplet 互连·热分布优化、多物理场 AI 分析」方向，把此前 ChipletNet-GNN（2609.13567）、PowerChip-GNN（2609.15388）的热或供电单场预测推进到「热-互连」双场耦合，与本站关注的「Chiplet 系统互连 / 热分布优化」主题直接对应。

🤖 EDAgent-SkillHub：面向 EDA 的 AI Skills 与 Agents 协同市场——社区可发布/复用针对 EDA 的智能体技能，统一评测与版本管理，技能库覆盖 RTL→GDSII 全链路

当前 EDA 智能体的落地瓶颈之一是技能碎片化：每个团队把「综合/验证/布局布线」封装成各自私有的 Agent Skill，难以跨项目复用，也没有统一评测与版本治理（呼应本站 09-18 收录的 OpenEDA-Agent 2609.15600 指出的「工具层太碎」）。EDAgent-SkillHub 提出一个面向 EDA 的 AI Skills 与 Agents 协同市场：用统一的技能描述规范（接口契约 + 输入/输出 schema + 依赖环境）让社区发布与复用针对 EDA 的智能体技能，平台提供自动评测（在标准化 RTL→综合→验证→布局布线容器上跑 pass/fail + QoR 回归）与语义版本管理（技能变更自动触发下游影响分析）；并附带技能组合推荐，按设计阶段把单点技能编排成端到端流水线。首发技能库已覆盖 RTL 生成、Lint、形式验证、OpenROAD PnR 等 30+ 预置技能，在 EDA-AgentBench（2609.12031）子任务上复用社区技能使新智能体端到端一次通过率从 41% 提到 52%。属「AI Agent / 开源基础设施·技能生态」方向，把「EDA 智能体真正跑通 RTL-to-GDSII」从单点工具升级为有治理、可复用的技能生态，与用户关注关键词「各种开源的针对 EDA 的 AI Skills / agents 新能力」直接对应，也为 OpenEDA-Agent 的 MCP 封装层补上「技能发现与评测」这一缺失环节。
