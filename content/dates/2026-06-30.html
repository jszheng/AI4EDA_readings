🤖 Siemens Fuse EDA AI Agent：从 RTL 到签核的端到端自主芯片设计智能体

AgentMarketCap 在 NVIDIA GTC 2026 和 Semicon China 2026 后发布 Siemens Fuse EDA AI Agent 深度分析，核心要点：

  • 端到端自主流：Fuse 不是 CAD 工具上的聊天机器人，而是横跨架构探索、RTL 编码、验证、布局布线、时序收敛到制造签核的完整流程编排智能体
  • 三层架构：Foundation（多模态 EDA 数据 RAG，包括原理图、网表、波形、版图几何、时序报告）、Orchestration（MCP 安全智能体编排 + Agent Skills）、Tool-Agent（RTL Code Agent、Lint Agent、CDC Agent、Testbench/Debug Agent、Place-and-Route/Timing Agent）
  • 工具覆盖：Catapult（前端）、Questa One（验证）、Aprisa（物理实现）、Solido（定制设计）、Veloce（硬件辅助验证）
  • 推理基座：基于 NVIDIA Llama Nemotron 模型和 NIM 微服务，支持 NVIDIA Agent Toolkit
  • 市场定位：Siemens 押注跨工具编排和 MCP 互操作性，与 Cadence ChipStack（JedAI 平台深度整合）和 Synopsys AgentEngineer（L2→L5 能力阶梯）形成三种 agent 架构路线
  • 落地观察：Samsung 在发布首日即背书；独立第三方 tape-out 数据预计要到 2026 Q3 以后才会出现

文章认为 EDA 的 agentic 转变不是渐进升级，而是 40 年来首次工具流本身变得智能，而非由工程师驱动工具流。Fuse 的采购评估关键信号：端到端周期时间、跨工具交接质量、waiver-to-fix 比率。

🎨 MultModLM：首个面向 LLM 硬件原理图生成的多模态基准 — 99 个 RTL 模块 + 多阶段评估框架

提出 MultModLM，首个评估大语言模型从 RTL 描述生成硬件原理图的多模态基准。数据集包含 99 个多样 RTL 模块，覆盖算术、控制与状态机设计。针对原理图非唯一表示难题，提出多阶段评估框架：评分标准 + 自评估 + 跨模型评估 + 盲评 + 人工验证。实验发现：模型能生成视觉可解释的原理图，但功能正确性受限；且 LLM 评估器与人工评分几乎零一致，揭示 LLM-as-a-judge 在结构精确领域不可靠，亟需领域感知的结构评估与形式等价检查工具。
核心创新：多模态硬件原理图生成基准 + 非唯一表示评估框架 + LLM-as-judge 可靠性分析
标签：RTL生成 · 多模态基准 · 硬件原理图 · LLM评估 · 形式等价检查

🔧 kicad-happy：AI 编码代理的 KiCad 电子设计技能套件 — 12 项技能 / 零依赖 / 5,800+ 项目验证

开源项目 kicad-happy 为 Claude Code、OpenAI Codex 等 AI 编码代理提供 12 项 KiCad EDA 技能，覆盖原理图/PCB/Gerber 分析、SPICE 仿真、EMC 预合规（44 项规则）、BOM 与采购、JLCPCB/PCBWay 制造导出等全流程。纯 Python 3.10+、零必需依赖，无需安装 KiCad 即可解析其开放 S-expression 文件格式。已在 5,800+ 真实 KiCad 项目、312,956 元器件、531,418 网络上测试，808K+ 回归断言 100% 通过。
落地价值：AI 代理可直接参与电子设计审查、DFM 检查、数据手册交叉验证与制造准备，是 KiCad MCP 生态外又一重要开源能力。
