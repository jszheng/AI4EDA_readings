🧩 AI 正在重写 IP 游戏规则 — 半导体 IP 的创建与验证方式被彻底改变

随着半导体生态全面转向 AI，IP（知识产权核）的创建与验证方式正在被根本改写。文章指出，AI 不仅加速既有 IP 复用流程，更在改变 IP 从生成、验证到信任评估的全链路：生成式方法开始介入可复用 IP 块的设计，AI 辅助验证则用于快速确认复用 IP 的正确性，chiplet / 3D-IC 时代 IP 复用与互操作验证的复杂度进一步推高对自动化手段的需求。
核心看点：AI 对 EDA 的价值正从"设计内部优化"外溢到"IP 供应链"——IP 的自动生成、AI 辅助验证与信任 / provenance 评估成为新焦点。这与 Agentic EDA 的"从规格 / 意图到可复用硅 IP"闭环高度契合，对 RTL 生成、IP 验证与 chiplet 集成工具链提出新要求。

🎯 一个"用对场景"的 AI 模型 — EDA 中预测/代理模型须在训练语境内使用

Brian Bailey 指出，在模型被创建的语境之外使用机器学习模型，会导致误导性结果。这一告诫对 EDA 中日益普遍的预测 / 代理模型（时延、功耗、串扰、良率等 surrogate model）尤为关键：模型在被训练所覆盖的设计分布之外外推时，误差会急剧放大，可能让基于 ML 的 PPA 估计、时序 / 物理签核加速工具给出错误结论。
核心看点：ML for EDA 走向生产部署必须配套"模型适用性边界"治理——明确训练分布、输入约束与失效模式。这对物理设计中的 ML 代理模型、RTL / 模拟电路 LLM 辅助生成的可信度评估，是直接的方法论提醒，呼应了本站长期跟踪的"物理约束 / 分布外泛化"议题。

📐 ThermoDSE：面向 Chiplet DNN 加速器的热感知综合设计空间探索

Chiplet 化 DNN 加速器为现代 AI 负载提供了平衡性能与良率的可扩展路径，但面临严峻的面积与热约束。ThermoDSE 是首个将细粒度任务建模、chiplet 粒度、核心粒度与关键物理约束（热 / 面积）统一纳入设计空间探索的框架，在统一仿真优化流程中联合考虑架构设计、任务编排与 chiplet 间通信。

🔬 NEMESIS：网表驱动建模与带反演感知 SPICE 锚定的方程合成

NEMESIS 提出面向运算跨导放大器（OTA）设计的多模态 LLM 框架，在快速近似解析模型与昂贵的精确 SPICE 评估间取得平衡。给定 OTA 网表与原理图，先识别电路原语，再逐步生成更精确的性能方程：优先复用此前对相似 OTA 调用的方程，否则由 LLM 直接从电路输入推导初始方程，并通过 SPICE 修复环路迭代精炼。
在商用 65nm PDK 的 5 种 OTA 拓扑上验证，偏置范围内平均相对误差 <7%，收敛后评估速度较全 SPICE 快约 4622x。IEEE LLM-Aided Design 2026 接收。
核心创新：网表驱动建模 + LLM 方程合成 + SPICE 锚定修复环路 + <7% 误差 + 4622x 加速

⚡ ATLAS：面向 DL 优化 FPGA 的自动化高级综合（HLS）

FPGA 架构日益集成领域专用 in-fabric hardblock（尤其主导 DL 计算的 GEMM）以加速推理，但利用其性能需手写 RTL。现有 HLS 工具不支持为自定义 hardblock 生成代码。ATLAS 提出从高层 DL 模型描述到 FPGA 硬件实现的完全自动化流程，无需用户手写 RTL 或显式实例化 hardblock：以 GEMM 为通用抽象层，包含 (1) hls4ml-GEMM 编译器前端（将 DL 层转为带架构无关 GEMM 调用的 HLS C）与 (2) GEMM IP Generator 架构感知后端（生成基于 hardblock 的 RTL wrapper，含 tiling 逻辑、控制 FSM 与调度元数据）。
在 11 个 DL 设计（FC / 卷积 / 注意力及完整 CNN / MLP / Transformer）上基于 Catapult + VTR 评估。
核心创新：端到端自动化 HLS + GEMM 通用抽象层 + hls4ml-GEMM 前端 + 架构感知 GEMM IP 生成器 + 免手写 RTL
标签：HLS · FPGA · GEMM · 深度学习 · 自动化综合

✅ HiFuzz：用于语义感知自适应 CPU Fuzzing 的分层强化学习

现代处理器验证因传统变异式 fuzzing 效率低而难达深层架构状态。HiFuzz 提出分层强化学习框架，以结构化两层生成过程替代变异：Program Agent 负责全局布局，Basic Block Agent 负责精确指令填充。为克服奖励稀疏，集成自适应覆盖奖励机制与语义感知基本块编码器提供内在反馈。
在三个真实 RISC-V 核上评估，覆盖率与缺陷检测均显著优于 SOTA fuzzer。ITC 2026 接收。
核心创新：分层 RL + Program/Basic Block 双智能体 + 自适应覆盖奖励 + 语义感知编码器 + RISC-V 验证
标签：强化学习 · 验证 · Fuzzing · RISC-V · 处理器验证
