🔧 chip-claw：从零实现的 RTL 设计 Agent——自然语言生成可综合 Verilog + testbench，四层上下文压缩 + 文件记忆 + 子代理

chip-claw 是一个基于 mini-claude 架构、用 TypeScript 从零实现的 RTL 设计 Agent。核心能力：①RTL 生成——用自然语言描述模块功能，自动生成可综合 Verilog 代码与配套 testbench；②Agent 循环——流式 LLM 调用 + 工具使用，支持自动重试、预算控制（--max-cost / --max-turns）、中断恢复（Ctrl+C）；③上下文管理——四层压缩管道保证长会话不溢出上下文窗口（Budget 动态裁剪大体量工具结果 / Snip 占位符替换过时读取 / Microcompact prompt-cache 过期后激进清理 / Auto-compact 达 85% 容量时 LLM 生成摘要）；④记忆系统——基于文件的持久化记忆（user / feedback / project / reference 四类），通过 LLM sideQuery 异步语义召回；⑤Skill 系统——斜杠命令工作流（/gen-module、/verify、/lint-fix）；⑥RTL 知识库——通过 submodule 提供可复用 RTL 规范/协议/模板/testbench/bug pattern，生成前检索相关经验；⑦SubAgent——将探索/规划/代码审查委派给隔离子 Agent 实例；⑧双后端同时支持 Anthropic API 与任意 OpenAI 兼容接口，CLI 经 npm link / npm pack 安装。这是「LLM 原生 RTL 设计智能体 + 长上下文工程化」方向的轻量开源代表作，对「开源 EDA AI Skills / Agents 新能力」有参考价值。

🔧 K-RAG_guided_RTLGEN：基于知识 RAG（AST + DFG 双视图）的 GenAI RTL 生成器

K-RAG_guided_RTLGEN 是一个 GenAI 驱动的 RTL 生成器，用知识 RAG（Knowledge RAG）引导生成过程，其知识库同时基于 AST（抽象语法树）与 DFG（数据流图）两种代码视图构建。核心思路：把 RTL 代码的结构化知识（语法树拓扑 + 数据依赖）作为检索对象，在生成前/生成中召回相关模式，提升 LLM 产出 RTL 的正确性，缓解纯生成式方法在语义与结构一致性上的短板。项目定位为早期研究型仓库，延续了 AutoVCoder 领域特定 RAG 等「RAG 增强 RTL 生成」路线，并以 AST+DFG 双视图扩展结构化知识表征。对用户关注方向中的「RAG for Verilog / 检索增强 RTL 生成」是直接补充，可作为后续工程化（接入 Verilator/Yosys 反馈闭环）的起点参考。

🧪 CHORUS：面向高覆盖 testbench 激励生成的「互补专家」后训练框架——4B 模型在 CVDP-ECov 达 88.0% Pass@1，超 DeepSeek-R1(671B) 13.5 个百分点

硬件验证消耗现代芯片设计的大量精力，高覆盖 testbench 激励生成是关键任务。CHORUS 提出一个超越「常规 SFT → RL」流水线的后训练框架，核心基于两点观察：①分阶段 SFT 产生行为多样的 checkpoint，稠密奖励 RL 把它们变成聚合性能相近、但任务级优势各异的强专家；②这些互补优势可通过免训练模型合并（training-free model merging）或进一步后训练来利用，从而超越最优单专家。最终把多位专家整合进单个 4B 模型，在 CVDP-ECov 基准上取得 88.0% Pass@1，较 DeepSeek-R1（671B）高出 13.5 个百分点。作者含 NVIDIA（Brucek Khailany）与 Jishen Zhao，是「LLM 驱动验证激励生成 / 验证反馈闭环」方向的高信号工作，对小模型高效化验证生成有直接启示。

📊 NetlistBench：评测 LLM 在 SPICE 网表识别与操作上的可靠性——2342 例 / 24 任务族，确定性结构预言机揭示「结构保持」瓶颈

LLM 越来越多用于电路设计工作流，但其在面向仿真器的 SPICE 网表识别与操作上的可靠性仍知之甚少，且常被混同于高层设计推理。NetlistBench 提出一个结构验证（structure-verified）基准：含 2,342 例、覆盖 24 个任务族，包括参数/连接关系识别与编辑、层次化操作、等价性判断、长程复合编辑。模型输出由确定性结构感知预言机评估。在 6 个非思考（non-thinking）LLM 上：简单局部编辑达 96%–100% 准确率，而器件添加降至 41%–83%、等价性判断降至 49%–90%；开启推理显著提升弱模型但未消除结构保持失败，且随编辑跨度（edit horizon）增大性能急剧退化。论文将「网表可靠性」确立为可信 LLM 电路设计自动化的独立瓶颈——对「LLM→网表/RTL 生成」反馈闭环的评测与纠错有直接方法论价值（MLCAD 2026 录用）。
