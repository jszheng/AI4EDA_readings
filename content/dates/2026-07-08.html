🤖 AgenticPD：面向物理设计 QoR 优化的阶段感知智能体框架（Bei Yu / Tsung-Yi Ho）

物理设计质量-of-results（QoR）优化困难且昂贵，单阶段决策会波及后续阶段，每次评估都需昂贵的全流程 EDA 运行。现有方法仍把优化当作扁平参数调优或 LLM 脚本生成任务。本文提出 AgenticPD，一个以物理设计流程阶段边界组织的阶段感知（stage-aware）智能体框架：Judge Agent 负责导航搜索，阶段专属智能体利用阶段局部工具在各自阶段内做局部决策；agent harness 提供结构化观测、执行历史与上下文管理。系统可从先前中间状态分支、复用 checkpoint 续优化，每个候选均在 post-route signoff 评估。相比基线，AgenticPD 在保持功耗与面积竞争力的同时取得更强的 post-route 时序。
核心创新：阶段边界组织 + Judge Agent 导航 + 阶段专属智能体 + checkpoint 复用 + post-route 统一签核
标签：物理设计 · 智能体 · 时序收敛 · Post-Route Signoff · 多智能体 · Bei Yu

🔬 SABLE：面向工业 EDA 流程的 NDA 安全闭环 LLM 模拟电路优化框架

LLM 可提出电路优化决策，但工业模拟流程无法向云端暴露代工 PDK 内容、专有原理图、绝对仿真路径或 license 工具状态。本文提出 SABLE（Safe Analog Boundary for LLM-driven EDA），一个 NDA 安全的闭环框架，让 LLM 通过 Cadence Virtuoso / Maestro / Spectre 优化模拟电路，仅回传清洗后的拓扑意图、数值指标、工作点摘要与受控写回状态。"NDA 安全"指在"好奇但被动"云服务商威胁模型下的强制约束（非形式化非干扰证明）。框架含明确威胁模型、28 个受控 SKILL 入口白名单、每条返回路径的 PDK/路径/模型清洗、结构化 Maestro 设置与写回、带 6 个机器检查停止条件的严格 JSON 动作契约、最优状态保持。在两个真实闭环任务（20GHz LC-VCO 调谐曲线、两级运放）上以 PVT 三角验证：LC-VCO 任务 11 个模型中 7 个通过；更难的运放任务（最差角所有指标须保持、相位裕度门限剔除不稳定高增益点）在 15 轮预算内 11 个中 4 个通过。反馈路径消融显示移除任一清洗通道会静默削弱规格或劣化搜索。
核心创新：NDA 安全边界 + 28 SKILL 白名单 + 路径清洗 + JSON 动作契约 + PVT 多角闭环验证
标签：模拟电路 · LLM闭环 · NDA安全 · Cadence Virtuoso · 工业EDA · 多角验证

🤖 ArchEval：评测 AI 智能体作为计算机架构师的能力基准与平台

计算机架构长期依赖基准驱动进步，而 LLM 智能体带来不同的度量难题：成功不只是写代码或调参，还要解读工作负载、选择机制、使用模拟器、预测性能、满足硬约束并决定哪个可行设计值得评估。本文提出 ArchEval，评测 LLM 智能体在计算机架构设计与优化上的基准与平台：含 CPU 核机制、系统架构、存储系统、加速器、存内计算 5 大类 20 个挑战，背靠 8 个模拟器；每个挑战设三种设置——L1 完整 harness（有重复模拟器反馈）、L2 模拟器-代码容器（需自行组装工作流）、L3 仅智能体（提交前无可用反馈）。每轮报告基线归一化验证性能并记录完整轨迹，关联工作负载分析、模拟器工具使用、预测、约束处理与产物完整性。初测显示清晰边界：L1 下 4 个智能体均达/超基线并改进真实设计；移除支持后暴露弱点（多数无法将模拟器源码转为有用实验，L3 预测常与验证结果不符）；L3 仅 GPT-5.5 + Codex 高于基线（1.21x 几何均值、65% 胜率），其性能建模通过率仅 15%。ArchEval 将今日智能体定位为有用优化助手而非自主架构师。
核心创新：架构师智能体基准 + 20 挑战/8 模拟器 + L1/L2/L3 三档设置 + 轨迹级评测
