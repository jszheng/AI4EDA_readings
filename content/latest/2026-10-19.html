✅ Independent Data-Integrity Verification for LLM-Driven Functional Coverage Closure in Hardware Design——面向硬件设计的 LLM 驱动功能覆盖收敛的独立数据完整性验证

LLM 智能体可写定向测试来闭合功能覆盖，但「覆盖」只表明到达了某个状态，并不保证沿途数据正确——这是验证领域长期已知的盲点，本文并未声称其为新发现。作者描述一个小型覆盖收敛智能体，把它接入 LLM 闭环：覆盖率从仿真自身导出的报告（cocotb-coverage YAML）读取、绝不采用模型自报的账本，并由与模型解耦的记分板（scoreboard）做数据完整性校验。在三个架构各异的 RTL 设计（异步 FIFO、UART 发送器、AHB2APB 桥）上，该智能体把覆盖率从 91.7% / 88.9% / 67.4% 进一步提升。属「功能验证 / LLM 辅助验证闭环、覆盖收敛」方向，凸显了「验证裁判与生成作者解耦」这一可信 AI4EDA 的关键原则。

🔬 LOADBench: A Large Open Analog Dataset and Benchmark for Machine Learning in IC Design——LOADBench：面向 IC 设计中机器学习的大型开放模拟数据集与基准

机器学习用于模拟 IC 设计长期受限于开放数据稀缺与缺乏标准评测：不同论文用各自封闭数据集与临时指标，跨方法比较不可靠。本文同时填补两块空白——提供大型开源数据集与一套标准化基准。数据集含 100+ 运算放大器（opamp）拓扑（1/2/3 级），均基于 SkyWater130 PDK，每个附带结构与功能标注、拓扑特定的尺寸约束（对称与尺寸规则）、Ngspice 测试平台，以及多目标 NSGA-II 尺寸优化运行产物。属「模拟与架构 / 模拟电路设计自动化（开放数据集 + 基准）」方向（MLCAD 2026），为模拟 IC 设计的 ML 方法提供可复现、可比较的评测基座。

📐 GNN-Guided Local Refinement for Efficient Layout Decomposition with DSA-MP——面向 DSA-MP 高效版图分解的 GNN 引导局部精化

多重 patterning 光刻（MPL）在先进节点用于提升光刻分辨率，但特征尺寸缩小后成本受限。定向自组装（DSA）作为高性价比补充，把光学光刻分辨率拓展到 10nm 以下；将 DSA 融入 MPL（DSA-MP）进一步增强接触孔/通孔的图形化分辨率。然而设计复杂度上升暴露出现有分解方法的局限：难以兼顾解质量与运行时间，且忽略 DSA 模板的边到边间距约束，损害可制造性。为此本文提出一种新的冲突图模型，并以 GNN 引导的局部精化在质量与效率间取得平衡。属「物理设计 / 计算光刻（版图分解、DSA-MP）」方向，ICCAD 2026 录用。
