📰 Chip Industry Week In Review #146 — ADI $15亿收购 Empower Semi、Arteris NoC 接入 imec IC-Link、CCRAFT $7.8M TFLN 代工

SemiEngineering 本周行业周评（#146）覆盖半导体与 AI 生态多项动态，其中与 AI4EDA / AI 芯片设计最相关的包括：

  • ADI 完成 $15亿（约¥108亿）收购 Empower Semi：Empower Semi 是集成式电压调节器（IVR）厂商，收购强化 ADI 在 AI 芯片供电 / 电源完整性领域的布局，直接关联 AI 加速器 PDN 与签核
  • Arteris NoC IP 接入 imec IC-Link 高速 I/O 参考设计：面向 AI / HPC ASIC 的片上网络 IP 将集成进 imec 高速 I/O 子系统参考设计，加速 Chiplet / 多芯粒互连方案的落地
  • CCRAFT 融资 $7.8M 扩建薄膜铌酸锂（TFLN）代工：光子互联关键材料产能扩张，支撑 CPO / 硅光子 AI 互连
  • Syntiant 递交纳斯达克 IPO：物理 AI（Physical AI）处理器 / 传感 / 软件厂商，边缘 AI 推理芯片商业化提速
  • 其他：e-peas $22M 能量采集电源管理、Pixel-Flo $7M MicroLED 流体自组装、Swissbit×Nexperia 安全高可靠硬件（AI/云/服务器）
核心看点：本期 AI4EDA 相关主线集中在AI 芯片供电（ADI/Empower）、Chiplet NoC 互连（Arteris×imec）、光子 TFLN 代工（CCRAFT）——分别对应电源完整性签核、多芯粒互连 IP、CPO 光电互连三大后端 / 系统级方向，与本站长期跟踪的物理设计 / 多物理场 / Chiplet 主题高度契合。

🔧 verilog-generator：面向 Verilog-2001 RTL 生成与 FPGA 设计工作流的开源 Agent Skill（v0.3.6）

东南大学电子科学与工程学院异构智能与量子计算实验室（HIQC）发布开源 Agent 技能包 verilog-generator（Apache-2.0，v0.3.6），面向 Verilog-2001 RTL 生成与 FPGA 设计工作流。技能强调 disciplined RTL 工作流：规范对齐、模块分解、可综合编码、testbench / 仿真闭环，可作为 AI Agent 在真实 EDA 流程中生成与验证 RTL 的"能力插件"。
作者 Jiyuan Liu、He Li。延续本站持续跟踪的"开源 EDA Agent Skills / MCP"脉络（kicad-happy、eda-agent、kicad-mcp、solder-mcp 等），显示面向芯片设计的开源智能体技能生态正从 PCB 向 RTL 前端延伸。
核心看点：开源社区在 RTL 生成 Agent 技能方向补齐了 disciplined、可验证的工作流范式，与工业界 Renoir / ChipAgents 等专用大模型形成互补，降低 Agentic RTL 生成的工程门槛。
