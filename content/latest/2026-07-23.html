🔧 VeriRefine：把规格精化提升为可验证阶段的渐进式可综合 RTL 生成

LLM 可直接从自然语言规格生成 RTL，但失败多源于理解而非编码：规格非形式化、含歧义，模型的解释隐式进行，所有误读都被静默写进 Verilog，只有仿真才能暴露。VeriRefine 把规格精化（specification refinement）作为 RTL 生成的一个可验证阶段——渐进式将 prose 规格精化为显式、schema 约束的"设计意图"账户，以逐信号的 Abstract Signal Transition Functions (ASTF) 表示，在生成任何代码前就固定每个信号的逻辑风格、时钟域与复位行为，并锚定到逐字规格句。
核心机制：精化后的规格经五层审计（健全性、完备性、一致性、FSM 完整性、核心 RTL 设计规则），于表示层修复理解错误；代码生成后每个仿真失败被分类为"理解错误"或"编码错误"并路由回对应阶段做针对性修复。因每个信号的硬件类在精化期已固定，可综合性成为流水线的结构属性而非事后检查。
核心结论：基于 Claude Sonnet 4.6，VeriRefine 在 RTLLM v2.0 达 94.0% 功能正确率、VerilogEval-Human v2 达 98.1%。
核心创新：把"规格理解/精化"从隐式、易错的黑盒提升为可验证、可审计的一等阶段——延续本站对 LLM RTL 生成-验证闭环（VeriPilot / MechMem-RTL / RTLScout）与"理解先于编码"主线（EstRTL / LongRTL）的跟踪，并直指 RTLLM/VerilogEval 等基准痛点。

📐 MAGE：类专家的多模态多智能体宏布局 — 六阶段工作流 + 锦标赛式细化，WNS 改善 11–19% / TNS 70–74% 超商业布局器

工业物理设计流程中宏布局（macro placement）仍高度依赖人工精修。本文提出 MAGE（Macro Placement Agentic Engine），一个多模态多智能体宏布局细化框架：将宏布局任务分解为六阶段工作流，融合结构化布图规则、视觉检查与迭代细化；专家布图知识以自然语言指令 + 验证准则编码，而非从带标签布局数据学习。
核心机制：引入锦标赛式细化（tournament-style refinement）模式，评估多个候选布局并把更高质量解的反馈传播下去；并提出四项量化"human-likeness（类人度）"的指标——notch / whitespace / pocket / alignment score，捕捉专家设计者使用但传统 PPA 指标不直接度量的结构性质。
核心结论：在 NanGate45 与 GlobalFoundries 12nm 共 9 个设计上，MAGE 相对商业宏布局器取得 WNS 几何均值改善 11.1%–19.3%、TNS 改善 70.0%–74.0%；在 3 个有人类专家与 Hier-RTLMP 基线的 NanGate45 设计上，相对人类专家 WNS/TNS 改善 18.3%/72.5%、相对 Hier-RTLMP 改善 47.0%/80.4%，线长与功耗相当；在类人度指标上整体得分较所有基线高 6%–48%。
核心创新：多模态多智能体 + 结构化专家知识（非数据驱动）+ 锦标赛式细化 + 类人度量化，刷新宏布局 SOTA——延续本站对布局优化（CoEvoP&R / DREAMPlace / GNN Placement）与"LLM+物理设计"主线的跟踪，且由 EDA 泰斗 A.B. Kahng 组产出。
