⚡ CorrectRTL: Boost RTL Generation Quality Through Automated Self-Correction with Instruction Decomposition——CorrectRTL：基于指令分解的自动化自校正提升 RTL 生成质量

大语言模型（LLM）在「规格→RTL」生成上展现强潜力，自校正范式显著推进了该方向，但两重挑战限制进一步进展：现有基准已被先进 LLM 饱和，难以评估智能体自校正框架；单体自校正一次重写整个设计，LLM 易受错误混淆、破坏原本正确的代码。针对基准挑战，本文贡献 ScaleBench——含 200 个复杂 RTL 设计的更具挑战性基准；针对方法挑战，提出 CorrectRTL——实现「先分解后校正」新范式的智能体框架，显式解耦脚手架构建与细节实现，含三项核心技术：面向结构的分解、基于代码片段的 RAG、基于 SVA 的自校正。在 ScaleBench 上，CorrectRTL 将 Pass@1 从 20.5% 提升至 49.0%（+28.5%）；在 VerilogEval 上取得最高 96.1% 的 Pass@1，在简单与复杂设计上均一致提升。属「前端 RTL / 智能体自校正 RTL 生成（指令分解 + SVA）」方向。已录用 ICCAD'26。

⚡ Search-Guided Reasoning Trace Curation for Verilog Generation——面向 Verilog 生成的搜索引导推理轨迹筛选（MCTS-SFT）

近期 LLM 提升了 Verilog 生成，但多数训练管线蒸馏自然语言推理轨迹，其中间设计决策结构松散、主要依据最终 RTL 正确性筛选。本文提出 MCTS-SFT——一个验证器引导的框架，用于策划 Verilog 生成模型监督微调（SFT）的推理轨迹：将轨迹构建建模为对中间推理状态的搜索，并用蒙特卡洛树搜索（MCTS）把完整 Verilog rollout 的功能反馈传播到更早的设计决策。在此框架内引入 Plan-MCTS，在显式表示接口、时序、状态、行为与更新规则的紧凑硬件设计计划上搜索；并研究计划保持监督（把搜索到的结构化状态保留为下游 SFT 目标）。实验表明 Plan-MCTS 取得最高功能轨迹产出率（84.2% 正确轨迹 vs 一次性结构化规划 81.9% / 无引导树搜索 82.0%）；在相同的 Plan-MCTS 轨迹与 Verilog 输出下，SFT 中保留显式计划把 pass@10 从 52.56% 提升到 57.7%；一项 6000 轨迹研究里，MCTS 策划的监督比完整回复的链式思维蒸馏 pass@10 最高提升 3.7 个点，同时把下游生成长度缩短约 50%（VerilogEval-v2）。表明结构化硬件规划、验证器引导搜索与显式中间状态监督可互补地构造更有效的 token 高效训练数据。属「前端 RTL / 验证器引导的 Verilog 生成训练数据策划（MCTS-SFT）」方向。

🔬 The Code Behind the Layout: AI Agents for Analog Layout Generators——版图背后的代码：面向模拟版图生成器的 AI 智能体

模拟版图至今仍高度手工、难以自动化。gLayout 等生成器框架把版图表达为程序，由参数化、感知设计规则的生成器产出版图；但编写这类生成器仍需专家投入。LLM 现已能写生成器代码，前沿模型甚至能依设计意图直接绘制版图几何。这引出实际问题：若模型能直接绘制版图，生成器框架还有什么价值？把模型用于生成器框架是否优于从零绘制？通过在 SKY130 上 gLayout 的受控实验，本文发现直接绘制的主要障碍是时间与 token 成本，而基于生成器框架建模的主要优势是可复用性——其经验证的原语让每次模型编辑足够小以便于检查，其参数让一次编辑能在整个版图族上评估。因此模型最有效的做法是：从设计意图所属族群的生成器源码出发开发版图，并在最可能出现故障的族成员上测试每次编辑，使一次经验证的改动改善生成器产出的每一个版图；这些族测试结果可作为本地模型的监督，以远低于推理成本的代价学到跨族普适的编辑。属「模拟与架构 / LLM 智能体驱动模拟版图生成器（可复用性 + 经验证原语）」方向。
