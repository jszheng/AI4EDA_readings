🟢 OpenROAD-MCP 发布 v1.0：OpenROAD 官方 MCP 服务器切换 TypeScript 主线，npx 一键接入 10 个工具

The-OpenROAD-Project 旗下的 OpenROAD-MCP（Model Context Protocol 服务器）在 8/6 密集完成 v1.0 TypeScript 化主线切换（#161 Chore/v1.0 ts primary），正式弃用 Python/PyPI 分发、以 npx 为首选安装方式，并配套修复 2 个依赖安全更新（cryptography 50.0.0、ip-address 10.4.0）。服务器固定提供 10 个 MCP 工具（zod schema 注册、冒烟测试断言），安全模型区分 query（只读）与 exec（执行），含命令白名单、路径遍历防护、PTY 进程隔离；支持 stdio 与 streamable-http 双传输，兼容 Goose / Cody / Codex CLI / GitHub Copilot CLI 等主流 MCP 客户端。这让任意 MCP 兼容 AI 智能体可通过标准协议驱动开源 RTL→GDS 布局布线工具、管理交互式会话、取回报告，是「AI Agent + 开源 EDA」落地的重要基础设施。

🤖 EDATracer：面向大规模 EDA 工件分析的证据锚定智能体框架——知识图谱 + 语义向量索引，18.9GB / 2,787 开源设计基准

现代芯片设计依赖 EDA 工具产生海量异构工件（源文件、脚本、日志、网表、报告），其分析对调试、优化与流程理解至关重要，但相关证据常分散于多种工件类型与设计阶段，LLM 智能体也缺乏公开的大规模跨工件分析基准。EDATracer 提出一个证据锚定（evidence-grounded）的 EDA 工件分析智能体框架：把设计工件组织为「知识图谱 + 语义向量索引」，让 LLM 智能体跨源文件、日志、网表、报告检索证据。作者整理出 18.9 GB、2,787 个可综合开源芯片设计数据集，并引入涵盖事实 / 统计 / 推理三类任务的 90 题基准。在受评智能体中，EDATracer 取得最佳 pass@1 准确率，平均比 Cursor、Claude Code 分别高 6.4 与 7.2 个百分点，同时少用 2.0–3.2× token。这是「AI Agent + 开源 EDA」落地的重要基础设施级工作。

🔐 PDMarks：Kerckhoffs 合规的物理设计 IP 水印框架——贯穿布局/CTS/布线，已集成 OpenROAD-flow-scripts

物理设计（PD）IP 是现代 VLSI 实现的关键资产，含经调优的单元布局、时钟树与布线决策；随 PD 工具普及，未授权复用已布局布线数据库的风险上升。现有 PD 水印要么只保护单一阶段、要么依赖隐藏构造细节，难以抵御白盒对手。本文提出 PDMarks：一个安全性仅依赖密钥的 Kerckhoffs 合规水印框架，将所有权证据嵌入 PD 流程的多个阶段（布局、时钟树综合 CTS、布线），所有水印实例与目标值均通过 HMAC-SHA256 由 32 字节密钥确定性派生，保证嵌入与验证一致。PDMarks 已集成进 OpenROAD-flow-scripts；在 NanGate45 与 ASAP7 设计上，其所有权证据显著强于既有方法，PPA 开销相当或更小，全阶段联合重合概率低于 10⁻³²，错误密钥无法复现完整所有权证明。这是开源 EDA 流程 IP 保护的高水位工作。

🛡️ LLM 辅助检测并修复 Verilog 设计中的硬件安全漏洞——基于 CWE 框架的迭代式弱点识别

硬件设计如同软件，易受可能引入安全漏洞、遭恶意利用的 bug 影响；但不同于软件漏洞，硬件缺陷一旦流片便永久固化于硅片，难以修补。许多此类弱点归属于 CWE（Common Weakness Enumeration）框架，如不当访问控制、敏感信息泄露、非预期权限提升。本文提出一种方法论，利用 LLM 直接从 Verilog 设计识别潜在硬件 CWE，并在单模块 Verilog 设计数据集上迭代评估其检测有效性。结果表明：LLM 有潜力增强传统硬件安全分析，在设计过程中提供自动化、可扩展的漏洞识别辅助。这是「LLM + 硬件安全」「RTL 验证反馈闭环」方向的直接进展，与本站收录的 LLMs for Secure Hardware Design 综述、OpenFV-RTLRepair 等形成互补。

🎛️ ORACLE：多目标强化学习 + LLM 引导探索的模拟电路设计优化器——runtime 最高降 104×，开源

用强化学习（RL）做模拟电路设计自动化已成减少人工投入的有力方向，但许多既有 RL 方法聚焦单目标，或把多目标简化为单一标量奖励，难以捕捉真实 Pareto 权衡，且每当目标规格变化便需从头重训。ORACLE 是一个开源的多目标模拟电路设计优化 RL 框架：用向量值学习 + 偏好感知条件（preference vector 指定多目标相对权重）替代标量奖励优化，使单一训练模型无需重训即可跨多样权衡设定生成设计；并提出归一化权重引导、余弦对齐引导两种偏好引导策略加速收敛；还引入 LLM 引导的动作选择机制，过滤可能通向次优设计或增加运行时的动作。在多个电路拓扑 2,000 个测试用例上，ORACLE 相对 SOTA 把运行时降低 20.4×–104.4×，满足 99.9% 的目标规格，输出 FOM 提升 5.1×–318.6×。这是模拟/混合信号 AI4EDA 的高价值开源贡献。
