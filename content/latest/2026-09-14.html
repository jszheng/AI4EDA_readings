🧩 Fengshui: Demystifying Chiplet Ecosystem and Bespoke Neural Network Accelerator Codesign——chiplet 生态与定制 ASIC（BASIC）协同设计，联合优化芯粒池构成与算子级解耦，含布局布线（P&R）物理可实现性验证

现代 ML 负载对时延与能效约束严苛，同质商用硬件难以高效承载；算子级解耦（为每个算子定制微架构、批处理与存储层次）能突破瓶颈，但高度定制加速器的非经常性工程（NRE）成本 prohibitive。Chiplet 集成把 NRE 摊薄到多应用，但「选哪些芯粒、如何拼成加速器」与加速器质量循环依赖。Fengshui 提出 chiplet 生态与加速器协同设计框架，联合优化芯粒池构成与定制 ASIC（BASIC）设计：通过算子级解耦构建 BASIC，协同探索芯粒与存储异构、张量融合、流水线/张量/专家并行，并以布局布线（P&R）验证保证物理可实现性。仅用 8 个策略性选取的芯粒（含网络交换、存内处理单元、多种微架构加速器），Fengshui 生成的 BASIC 相对同质加速器在能耗、能耗成本积（EC）、能耗延时积（EDP）、能耗延时成本积（EDPC）上分别降 48.5% / 88.1% / 93.0% / 97.8%，且距无约束异构设计仅差 4.1%；数据中心 MoE 与稠密 LLM 服务的 prefill 能耗与 EC 最高降 16.8% / 28.7%，边缘自动驾驶感知在实时时延约束下能耗降 12.0%、EC 降 23.6%。属「模拟与架构 / Chiplet 协同设计」方向，用「芯粒池 + 定制 ASIC 联合优化 + P&R 验证」把多芯粒加速器设计空间探索做成可物理实现的闭环，与本站关注的「AI for Multi-Die/Chiplets、Chiplet 互连/系统协同」主题直接呼应。
