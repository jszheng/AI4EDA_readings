⚡ CircuitWeave：拓扑-行为对齐的可执行多模态 RTL 生成——从电路图抽取拓扑契约、从文本抽取行为契约，融合后仅依据契约生成 RTL

纯文本 LLM 能从自然语言规格生成 RTL，但散文即便给定接口与周期级行为，仍会让连接关系、寄存器边界、状态-输出关系保持隐式。电路图（schematic）能把这些结构关系显式化，但"直接把图喂给多模态模型"会遇到融合难题：文本与图的证据角色未被区分，缺失 / 冲突约束在生成前未被显式化。
本文提出 CircuitWeave：一个契约中介（contract-mediated）的多模态框架——从电路图抽取拓扑契约、从文本抽取行为契约，融合为序列化对应 / 缺失证据 / 冲突的"电路契约"，仅依据该契约生成 RTL；联合目标同时监督两类契约、序列化融合、契约条件 RTL 生成，以及从参考 RTL 反向重建已覆盖契约字段。
数据与方法：构建 5,000 个可执行达标包（规格 + 生成电路图 + 结构化契约 + 参考 RTL + 自检测 testbench），用训练拆分以 LoRA 适配 Qwen。
结果：在 VerilogEval-Human 上 pass@1 达 46.60%（较同架构无图版本 +8.46pt）、pass@5 61.49%、pass@10 65.39%；在 RTLLM 上达 40.00% / 48.00% / 52.00%（各 cutoff 较文本版 +2pt）。数据集已开源（HuggingFace）。
核心创新：用"拓扑+行为双契约"显式分离文本与图证据、显式化缺失 / 冲突，把多模态 RTL 生成从"图+文拼贴"升级为"契约条件生成"——延续本站 LLM RTL 生成-验证闭环（VeriRefine / MechMem-RTL）与多模态（图生 RTL）主线。

📐 AQFP 技术合法化与物理设计衔接：以"线宽–线深积最小化"的布局感知缓冲器 / 分裂器插入（后布局面积平均降 30%）

绝热量子通量参变（AQFP）是逼近香农极限的超低功耗超导技术，但其门级流水与显式扇出约束要求通过缓冲器 / 分裂器插入（buffer & splitter insertion）做技术合法化（路径平衡 + 信号分发），成为设计流程中关键且昂贵的步骤。已有工作最小化"插入单元数"与"逻辑深度"，却未准确刻画最终物理设计成本——其本质由电路宽度与深度的乘积决定。
本文把 AQFP 缓冲 / 分裂器插入重新定义为最小化线宽–线深积（width–depth product）这一布局感知度量（比单纯单元最小化更贴近真实物理面积），并首个给出该问题的形式化及 NP 完全性证明；进而提出把合法化与目标耦合的可扩展启发式。
结果：在标准基准上，较 SOTA 方法后布局面积平均降低 30%，仅增加 3% 的约瑟夫森结（junction）数量，单个电路最高降 61%。
核心创新：用"线宽×线深积"替代单元数作为合法化目标，使 AQFP 缓冲 / 分裂器插入真正对齐物理设计面积——延续本站物理设计（逻辑综合 / 合法化 / 单元插入）与超导 / 新兴器件 EDA 主线。

✅ ADVERSARIAL：AIG 辅助、知识图谱嵌入的硬件木马检测——把门级网表建模为布尔网络，节点表示随边数线性扩展

现代 SoC 常含数亿至数百亿门，使现有硬件木马（Hardware Trojan, HT）检测方法因规模过大而失效。本文提出符号使能学习（symbolically enabled learning）：把展平的门级网表建模为由与-非图（AIG）表示的布尔网络（所有内部节点为 2 输入 AND、反相在边上），每个有向连接在知识图谱嵌入（KGE）框架中表达为三元组，产出紧凑、定长、保留多跳结构上下文的逐节点表示。
AIG 的有界扇入与统一语义使训练 / 推理复杂度随边数线性扩展，直击 HT 检测的主要可扩展性瓶颈；跨深数据通路的符号使能学习让模型能区分电路结构与指示潜在木马触发器 / 负载的稀有、功能不一致连接。
结果：在大规模 SoC 基准上，木马与良性节点呈现清晰几何分离，并具备实用可扩展性。
核心创新：AIG + KGE 把"网表结构"转为可学习、定长、线性扩展的节点嵌入，为高规模门级网表的 AI 安全分析（木马检测）提供 scalable 基座——延续本站 AI 辅助验证 / 网表分析（WaveformQA / ChipFuzzer / Rtl2lean）与硬件安全主线。
