🔬 多芯粒现场测试必须建立在既有测试方法论之上

随着 AI 发展超出 IC 行业测试能力，多芯片系统需通过内置自测试（in-system testing）与片上监控确保数据中心和汽车硬件的可靠性与寿命。文章指出：

  • 基于 UCIe / PCIe 等高速接口与 IEEE 1838 标准的双芯片监控、测试与修复策略，可实现隐蔽裸片的访问及微凸点间接探测（借助牺牲焊盘）
  • 片上监视器 + DFT 技术预测失效、自动切换冗余通道，弥补制造测试难以覆盖的潜隐与间歇缺陷
  • Synopsys × TSMC 联合项目：物理感知的凸点修复与高速测试将桥接模式减少 95%–99%，为关键任务应用提供全生命周期健康管理基础
核心看点：多芯粒 / chiplet 系统的现场测试与健康管理成为 AI 芯片可靠性的关键瓶颈；UCIe / PCIe / IEEE 1838 + DFT + 片上监控构成解决路径，Synopsys×TSMC 实测桥接缺陷减少 95%–99%。该方向对 Agentic EDA 的 DFT / 硅后验证闭环提出新要求。

🤖 ArchEval：评测 LLM 智能体作为计算机架构师能力的基准与平台

ArchEval 提出评测 LLM 智能体在计算机架构设计与优化上的基准与平台。覆盖 CPU 核机制、系统架构、存储系统、加速器、存内计算 5 大类 20 个挑战，背靠 8 个模拟器。每挑战设三档设置：L1 完整 harness（重复模拟器反馈）、L2 模拟器-代码容器（需自行组装工作流）、L3 仅智能体（提交前无可用反馈）。每轮报告基线归一化验证性能并记录完整轨迹，关联工作负载分析、模拟器工具使用、预测、约束处理与产物完整性。
初测显示清晰边界：L1 下 4 个智能体均达 / 超基线；移除支持后暴露弱点（多数无法将模拟器源码转为有用实验，L3 预测常与验证结果不符）；L3 仅 GPT-5.5 + Codex 高于基线（1.21x 几何均值、65% 胜率），性能建模通过率仅 15%。ArchEval 将今日智能体定位为有用优化助手而非自主架构师。
核心创新：架构师智能体基准 + 20 挑战 / 8 模拟器 + L1/L2/L3 三档设置 + 完整轨迹记录

🔬 SABLE：工业 EDA 流中 NDA 安全的闭环 LLM 模拟电路优化框架

SABLE（Safe Analog Boundary for LLM-driven EDA）提出 NDA 安全的闭环 LLM 框架，让 LLM 通过 Cadence Virtuoso / Maestro / Spectre 优化模拟电路，仅回传清洗后的拓扑意图、数值指标、工作点摘要与受控写回状态。"NDA 安全"在明确"好奇但被动"云提供商威胁模型下强制执行（非形式化非干扰证明）。
框架融合明确威胁模型、28 个受控 SKILL 入口白名单、每条返回路径的 PDK / 路径 / 模型清洗、结构化 Maestro 设置与写回、严格 JSON 动作契约（6 个机器检查停止条件）、最优状态保持。在两个真实闭环任务（20GHz LC-VCO 调谐曲线、两级运放）以 PVT 三角验证：LC-VCO 任务 11 模型中 7 个通过；更难的运放任务在 15 轮预算内 11 个中 4 个通过。
核心创新：NDA 安全闭环 + 28 SKILL 白名单 + PDK 清洗 + JSON 动作契约 + 真实模拟电路优化
标签：LLM · 模拟电路 · NDA安全 · 闭环优化 · 工业EDA

📐 AgenticPD：面向物理设计 QoR 优化的阶段感知智能体框架

AgenticPD 提出以物理设计流程阶段边界组织的阶段感知（stage-aware）智能体框架，解决物理设计 QoR 优化昂贵且阶段间相互影响的难题。现有方法仍把优化当作扁平参数调优或 LLM 脚本生成，而 AgenticPD 围绕阶段边界组织：Judge Agent 负责导航搜索，阶段专属智能体利用阶段局部工具做局部决策；agent harness 提供结构化观测、执行历史与上下文管理。
系统可从先前中间状态分支、复用 checkpoint 续优化，每个候选均在 post-route signoff 评估。相比基线，AgenticPD 在保持功耗与面积竞争力的同时取得更强的 post-route 时序。CUHK Bei Yu 与 Tsung-Yi Ho 团队出品。
核心创新：阶段感知智能体 + Judge Agent 导航 + checkpoint 复用 + post-route signoff 评估
标签：物理设计 · AI Agent · 阶段感知 · QoR 优化 · Post-Route

📐 FAPlace：2.5D 系统中 Chiplet 布局与中介层面积联合优化

FAPlace 提出 footprint 感知的掩码引导顺序布局框架，联合优化 2.5D 系统中 chiplet 在硅中介层上的布局与中介层（interposer）面积。现有方法通常假设预定义中介层面积，形成循环依赖：最优面积需先解布局，而布局受给定尺寸约束。FAPlace 在足够大的画布上操作，让最优中介层面积作为优化输出自然浮现，而非预指定输入。
核心是融合面积紧凑性与宽高比惩罚的统一空间代价图（footprint mask），结合线长与热引导掩码，在确定性单遍过程中实现整体多物理场优化。实验表明 FAPlace 在降低线长与面积的同时实现接近 1 的宽高比，且不牺牲热性能。
核心创新：Chiplet + 中介层联合优化 + footprint mask + 多物理场（线长 / 热 / 宽高比）单遍优化 + GLSVLSI 2026
标签：Chiplet · 2.5D · 布局 · 多物理场 · 中介层
