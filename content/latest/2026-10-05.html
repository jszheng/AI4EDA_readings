⚡ Evidence-Guided Repository-Level RTL Repair——证据引导的仓库级 RTL 修复

仓库级 RTL 修复须定位跨文件、跨模块、跨时钟周期的故障，并一致地传播修复。现有方法仅在源码层面推理（能揭示可能行为却看不到失败执行，也无法判断局部修复是否一致传播）。本文提出证据引导框架，含三模块：① 故障定基——把问题陈述转为可复现的失败运行 + 失败锚点；② 波形引导定位——用定位工具箱把观测违例收敛为候选机理与证据链；③ 一致性感知修复与验证——把种子扩展为协同补丁并回放同一场景确认违例消失。在 HWE-Bench 上优于基线。属「前端 RTL / 生成-验证-反馈闭环」方向，把"失败执行级证据"引入 RTL 修复，直击 LLM 改代码缺乏执行验证的痛点。

⚡ SyntheticHLS: Building Diverse Synthetic High-Level Synthesis Datasets using LLMs——用 LLM 构建多样合成高层次综合（HLS）数据集

深度学习与 LLM 在半导体设计中快速普及，推高对训练数据的需求；既有工作多聚焦硬件描述语言（HDL），而高层次综合（HLS，领域专用加速器的主流路径）数据集稀缺，且偏手工整理或参数化，少有高质量 LLM 生成，也缺乏代码长度/层次/设计空间规模/时延/资源占用/应用域的多样性，限制模型泛化。本文提出 SyntheticHLS——用 LLM 生成大规模、复杂、多样合成 HLS 数据集的框架：① 反馈引导的迭代变异环（用配对 HLS 源码与设计空间规格把种子设计逐步演化为更复杂、可扩展的设计）；② 可量化的 HLS 设计复杂度与可扩展度指标（作为 LLM 引导变异的可测目标）。在常见 HLS 基准、零样本合成设计、迭代变异合成设计间交叉验证一个 HLS QoR 深度学习模型：合成设计对常见基准测试集迁移性好而反之不成立；迭代变异设计提供最具泛化性的训练语料，且变异轨迹在改善目标指标同时不回归非目标指标。框架、数据集与评测均开源。属「前端 RTL / HLS 数据驱动生成」方向，为 LLM+HLS 提供高质量、多样、可扩展的训练数据基础设施。

⚡ CITADEL: CWE-Guided Insertion of Hardware Trojans via Analysis of DFG-Enabled LLMs——基于 CWE 引导、DFG 赋能 LLM 的硬件木马插入

硬件木马（HT）与系统级漏洞日益复杂，构建真实 HT 场景负担沉重：研究者须手工分析复杂 RTL 结构、定位合理弱点、构造隐蔽且可综合、保持功能正确的插入。本文提出 CITADEL——用大语言模型（LLM）与数据流图（DFG）自动化 CWE 根基的 HT 综合：以结构化 CWE 语义结合 DFG 派生的结构上下文，辅助用户识别相关漏洞、定位插入点周边模块，并执行意图条件化的 RTL 修改；产出最小、可综合、保持接口的 HT（含极罕见触发器）。在多种 RTL 设计上的评估显示：所有生成 HT 100% 语法正确、在大规模随机仿真下不可检测、在预期激活条件下功能可触发。CITADEL 展示了"LLM+DFG 结构化分析 RTL"这一能力在硬件安全基准生成上的可扩展、原则化方法，也反向提示 RTL 结构分析智能体的攻防两面。属「前端 RTL / LLM+RTL 结构分析（安全基准）」方向。

📐 Timing-Driven Logic Remapping with Local Physical Context——带局部物理上下文的时序驱动逻辑重映射

映射电路的实际时序同时取决于逻辑实现与其所处的物理环境；在布局之后重新审视映射决策，需要一套考虑周边时序约束、扇出负载与互连效应的搜索流程。本文研究该场景下的局部重映射，提出把离散映射搜索与物理实现反馈耦合的框架：以有界窗口隔离时序关键区域（窗口接口保留周边电路上下文），在窗口内用混合整数规划联合选择逻辑切割、信号极性与库单元（延迟模型由估计位置与互连寄生驱动）；连续松弛先过滤搜索空间，再用离散优化产出时序相近、结构不同的替代实现，经合法化、基于布线的寄生估计与时序分析重建评估，把经物理验证的改进并入设计，更新后的上下文指导后续搜索。为"在已有布局约束下系统回访局部逻辑实现"提供方法。属「物理设计 / 布局后时序优化」方向。

📐 Vulnerability-Weighted Routing of Timing-Critical Nets for Configuration-Upset-Resilient SRAM-Based FPGAs——面向配置扰动鲁棒 SRAM FPGA 的时序关键网络脆弱性加权布线

传统 FPGA 布线优化时序、拥塞与可布线性，却不区分"标称性能相近但配置诱发时延退化敏感度迥异"的走线。本文提出面向 SRAM 型 FPGA 的脆弱性加权布线方法，把预测布线故障严重度直接纳入布线目标：连续脆弱性代价把"可被电性挂载的休眠布线资源"引发的时延扰动与下游可用时序裕度关联，配套的"配置集中度"项抑制脆弱资源的过度局部化；为减小实现扰动，仅对最高风险网络选择性撕除重布，其余路由保持不变。在 Zynq UltraScale+ XCZU7EV 上用 Vivado/RapidWright 流程实现，对照商业时序驱动布线、脆弱性无关重布、二进制脆弱资源规避，经受控配置等价扰动做硬件级验证：把配置诱发的总时序脆弱性降 41.7%，标称时序仅退化约 1.0%，且仅重布最高风险 5% 网络即捕获扩预算方案 85.8% 的脆弱性削减。同一作者延续 GRACIDIT 的 FPGA 配置诱发退化研究，属「物理设计 / FPGA 布线鲁棒性」方向。
