CPPL: A Circuit Prompt Programming Language

提出面向电路设计的提示编程语言 CPPL，解决 LLM 无法直接生成编译器 IR（MLIR/CIRCT）的核心瓶颈。核心思路：设计一种对编译器可见、对 LLM 友好的 JSON 格式电路中间表示（CPPL IR），结合 Python 前端 DSL 声明模块接口和层次结构，编译器自动推断位宽并验证生成的 IR，最终确定性地降级到 CIRCT 生成可综合 Verilog。在 RTLLM benchmark 上，CPPL 相比直接生成 Verilog 和直接生成 CIRCT IR，功能正确性显著提升；CIRCT 优化有效减少综合后的 AIG 节点数量。
作者：Shuo Yin, Yihe Wang, Lancheng Zou, Xufeng Yao, Tinghuan Chen, Chen Bai, Zhengrong Wang, Tsung-Yi Ho, Bei Yu（CUHK + SJTU）
