🌐 Physical AI：连接硅芯片、软件与现实世界 — Synopsys 定义 AI 驱动芯片设计新范式

Synopsys 博客发布 Physical AI 概念解读，提出将硅芯片、软件与物理现实世界无缝连接的技术范式。文章指出，随着 AI 从数字世界延伸至物理世界（机器人、自动驾驶、工业控制等），芯片设计必须同时考虑算法、硬件、传感器、执行器与真实环境的闭环。多物理场融合（Multiphysics Fusion）与 AI 驱动的 EDA 工具成为实现 Physical AI 系统的关键基础设施，覆盖从架构探索、RTL 实现、验证签核到系统级协同优化的全链路。
核心看点：Physical AI 作为 AI for EDA 的延伸场景，强调芯片设计工具需要理解并建模真实物理约束，而非仅优化数字指标。

🧠 Evidence-Driven LLM Agent：面向 HLS 的 C-to-Synthesizable-C 转换与验证智能体

提出首个面向高层次综合（HLS）工具链的端到端 LLM Agent 框架，将 C 到 HLS-C（可综合 C 子集）的转换形式化为闭环的生成-验证-诊断-修复问题。核心贡献：(1) 四阶段验证器（编译、CSim、综合、CoSim）在严格证据隔离下闭环的协作 Agent 工作流；(2) 渐进式不匹配定位链（PMLC），通过日志归一化、AST 后向切片和双轨迹插桩定位 CSim/CoSim 不一致；(3) 基于自演化、族路由修复卡池的类型查询两阶段证据 RAG。实验显示该工作流显著优于现有 SOTA 模型。
核心创新：HLS 全流程闭环 Agent + 证据隔离 + 渐进式不匹配定位 + 自演化修复 RAG
标签：HLS验证 · LLM Agent · 证据驱动 · RAG · 生成-验证-诊断-修复

🔗 SHIFT：通信感知 Chiplet 系统动态计算重定位框架

提出 SHIFT，一种拓扑无关的 Chiplet 系统运行时方法，通过将计算节点上下文与数据迁移到通信更优位置，而非像传统 NoC 仅迁移数据，来缓解大规模异构系统的通信瓶颈。基于细间距集成平台评估，采用多层路由连接功能/存储 Chiplet 与作为智能路由/计算重定位节点的 utility Chiplet，并结合轻量级 ML 辅助策略推断流量状况以提升自适应性。仿真显示重定位成功率 75.2%–97.9%，平均延迟改善 16.4%–62.5%，吞吐最高提升 12.5x，每比特能耗最高降低 58.3%。在 LLM 工作负载上，运行时、吞吐、能效分别平均提升 4.9x、5.9x、1.8x。
核心创新：拓扑无关计算重定位 + 多层 Chiplet 路由 + ML 辅助流量推断 + 通信感知布局
标签：Chiplet · 动态计算重定位 · 通信感知 · 多层路由 · ML辅助策略

🤖 ChatModel v5：LLM 驱动的参考模型自动生成与验证平台（重大更新）

提出 ChatModel，一个 LLM 辅助的敏捷参考模型生成与验证平台，解决 IC 设计复杂度上升导致功能验证越来越困难的挑战。通过设计标准化和分层敏捷建模简化从设计规格到完整功能参考模型的过渡；采用构建块生成策略增强 LLM 对参考模型的设计能力并提升验证效率。在 300 个不同复杂度设计上评估：峰值性能提升 58.99%，参考模型设计能力提升 9.18x，设计验证周期平均加速 7.11x。v5 版本于 2026-06-29 发布，论文大幅精简并更新实验结果。
核心创新：参考模型自动生成 + 分层敏捷建模 + 构建块生成策略 + 验证加速
标签：参考模型 · LLM · 验证 · 敏捷建模 · 层次化建模
