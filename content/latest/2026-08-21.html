🔬 NeuroAssertion（2608.18482）：覆盖驱动 RTL 断言生成——形式化轨迹生成 + SyGuS 语法导向合成 + 智能体式神经符号精化，突变覆盖约 2×

硬件功能验证依赖高质量断言来暴露设计缺陷、建立对 RTL 设计的信心；但既有断言挖掘方法难以产出完整可靠的断言集：随机/有限轨迹无法覆盖难达行为，一次性生成对「还有哪些未验证」缺乏反馈。本文提出 NeuroAssertion，一个覆盖驱动的断言生成框架，统一了形式化轨迹生成、语法导向合成（SyGuS）与受验证反馈引导的智能体式精化。流程：①将难达控制流条件转化为形式化可达性目标，用模型检验生成行为多样轨迹，经 SyGuS 从中挖掘初始断言；②在验证反馈下做针对性精化——一个 LLM 先为未覆盖区域提出候选断言，若候选未通过形式化检查，第二个 LLM 生成修复语法（repair grammar）引导约束式符号合成，形成神经符号修复。实验表明，框架相较传统断言挖掘产出约 2× 更多断言 与约 2× 更高突变覆盖。作者含香港科技大学（HKUST）Hongce Zhang 组（与 NeuroAbs 同组），属「LLM + 形式验证 / 断言生成 / 验证反馈闭环」方向的高信号工作，把断言生成从随机挖掘推向覆盖驱动 + 神经符号协同。

🔧 RTLLM v2.1 发布：经典 RTL 生成基准迎来质量修订——修正多个设计描述与 testbench 并同步更新受影响设计，直接影响既有论文的 pass@k 可比性

香港科技大学（HKUST）Zhiyao Xie 组维护的 RTLLM——LLM 自然语言生成设计 RTL 的开源基准（ASP-DAC 2024，v2.0 经 OpenLLM-RTL / ICCAD 2024 扩展至 50 个设计，分为算术 Arithmetic / 存储 Memory / 控制 Control / 杂项 Miscellaneous 四大类）——于 2026-08-15 发布 v2.1（仓库提交时间 08-16，覆盖 Arithmetic、Control、Memory、Miscellaneous 四个设计目录及 File_list.md、README.md、auto_run.py）。更新内容为两项质量修订：① 修正了若干设计描述（design_description.txt）与测试平台（testbench.v）；② 同步更新受影响的设计以保持一致性。维护者在 README 中明确致谢用户反馈的使用问题并就此前造成的困惑致歉。为何重要：RTLLM 是当前 RTL 生成类论文最常用的两大评测集之一（另一为 VerilogEval），本站近期收录的多篇工作均以其为主评测基准（如 VeriRefine 报告 RTLLM v2.0 上 94% 通过率）。描述歧义与 testbench 缺陷会把功能正确的设计误判为失败，因此 v2.1 的修订意味着历史 pass@k 数字的跨版本可比性发生变化，后续复现与横向对比需明确标注所用版本。这与同组 RTL-BenchMT（DAC 2026，以智能体流水线在六个上游基准中识别并修复 47 例提示歧义）构成同一条「基准质量治理」技术线。属「基准评测 / 数据质量治理 / RTL 生成」方向的高信号开源更新。
