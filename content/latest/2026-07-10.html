🤖 AI 正在重写 IP 规则手册 — GenAI / Agentic AI 渗入 IP 全生命周期

SemiEngineering 深度分析：生成式 AI（GenAI）与代理式 AI（Agentic AI）正嵌入半导体 IP 生命周期，覆盖 RTL 代码生成、调试加速、规范到测试场景的自动转换（spec correlation）、验证环境编排（orchestration）、覆盖率收敛与根因分析；AI 还作为"第二供应商 / 虚拟验证伙伴"并行辅助验证，并承担 IP 生命周期管理（自动打包、发现、保持生产就绪）。

  • Siemens EDA（GenAI、Agentic AI）称智能体创新集中在 RTL 生成与验证提速，使 IP 厂商能以更少资源快速推出"更多口味（flavors）"的定制 IP，并借助 AI 优化 chiplet 后端布局、bump array 与封装
  • Synopsys：AI 解析协议规范自动产生关联测试负载、编排千级模块验证架构、加速 debug 与覆盖率闭合；验证 IP（VIP）未被替代，而是由 AI 提升既有资产价值
  • Cadence（Tensilica DSP、NPU 加速器与 SDK）、IC Manage（AI 驱动 IP 打包与发现）、RAMbus（IP 许可像 Netflix 分层：单次 / 多次 / 订阅，chiplet 使单用途 IP 跨模块复用演变为多用途引发授权难题）、Arm / Expedera / Baya Systems 同步参与
  • 人力角色定位：Siemens"human on the loop"，基础任务自动化后人类转调度；Baya 称 AI 替代"平庸重复"工作而非专家；Cadence 指人类创意 + AI 协作令开发者更快更好
核心看点：AI 正把 IP 从"手工设计资产"重构为"可被智能体生成、验证、打包、复用"的活态资产；chiplet 多用途复用带来的授权 / 治理 / 所有权成为新约束。这直接对应 AI4EDA 的 RTL 生成—验证—IP 复用闭环方向。

SemiEngineering · AI 模型选型 · 2026-07-09 · Brian Bailey

🧠 为用途匹配的 AI 模型 — 芯片设计中 LLM / 小模型 / 智能体的边界与陷阱

Brian Bailey 文：所有模型都是对真实的妥协，仅在被定义的上下文中可靠；AI 生成模型若用于原意之外或数据分布边界外会产生误导。建议为模型打标签（tagging）附元数据定义范围，并在部署前做"边界探测（boundary-probing）"确认不确定性起点。

  • LLM 从规范生成 RTL / 模型代码 — Cadence 称 SystemVerilog 断言 / UVM 生成"时好时坏"，因标准松散
  • 小型代理模型 通过模仿学习，但原结构一变便失效（Normal Computing）
  • 强化学习优化循环工具：Synopsys DSO.ai 与 Cadence Cerebrus，基于 PPA 反馈自动调块级物理实现工具设置
  • 验证流中的代理 / 排序模型，从回归历史、覆盖库等学习推荐测试（Axiomise）
关键论断：LLM 在标准 Verilog 上语法正确近完美，但 VerilogEval 基准多为教学级短模块，工业级 SoC（如带 CDC 的缓存控制器）未覆盖，得分 90% 不代表实用；验证须用保留集（holdout）而非训练集；每模型需人签核且可追溯；AI 模型不应自 declare 验证收敛，须置于信任分析为终裁的有界循环（Axiomise）。
提及企业：Synopsys、Cadence、ChipAgents（六步建模法）、Keysight EDA、Axiomise、Normal Computing、Mirabilis Design、Siemens EDA、University of Southampton。该文为"AI 模型在 EDA 中的可信部署"提供了系统化的选型框架。

📐 ThermoDSE：面向 Chiplet 基 DNN 加速器的热感知综合设计空间探索

Chiplet 基 DNN 加速器面临面积与热约束的关键挑战。ThermoDSE 提出热感知的综合性设计空间探索（DSE）框架，首次将细粒度任务建模、chiplet 粒度、核心粒度与关键物理约束统一纳入联合优化。框架集成既有细粒度建模技术于统一仿真 + 优化流程，在严格热与面积约束下联合考虑架构设计、任务编排与 chiplet 间通信。相较 OTA Simba 等基线，Energy-Delay-Inverse-Yield 最高提升 3.5x；相较模拟退火与 强化学习方法，分别取得 3.7x 与 29.4x 运行时加速。

核心创新：Chiplet DNN 加速器 DSE + 热感知 + 架构 / 任务 / 通信联合优化 + 对比 RL / SA 取得 3.5x / 3.7x / 29.4x 提升

🔬 NEMESIS：网表驱动建模与方程合成 + 反演感知 SPICE 锚定的 LLM 模拟电路设计框架

NEMESIS 提出一个用于运算跨导放大器（OTA）设计的多模态 LLM 框架，在快速近似解析模型与精确但昂贵的 SPICE 评估之间取得平衡。给定 OTA 网表与原理图，NEMESIS 先识别电路原语，再生成逐步更精确的性能方程：优先复用先前同类 OTA 的调用方程，否则由 LLM 直接从电路输入推导初始方程；这些方程经 SPICE 修复循环迭代精化。在商用 65nm PDK 上于 5 种 OTA 拓扑验证，跨偏置范围产生 SPICE 验证方程，平均相对误差 <7%，收敛后评估较全 SPICE 评估提速约 4622x。已被 IEEE LLM-Aided Design 2026（斯坦福，7/30-31）接收。

核心创新：多模态 LLM + 网表驱动建模 + 方程合成 + SPICE 锚定修复循环 + 65nm PDK 5 拓扑 <7% 误差 / 4622x 提速
标签：LLM · 模拟电路 · OTA 设计 · 网表驱动 · SPICE 锚定
