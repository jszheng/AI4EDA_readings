🚀 Rapidus × Cadence 合作推进先进节点 SoC 设计的代理式 AI — Raads Navigator/Indicator 集成 InnoStack，目标 2× 加速 TAT

Rapidus 与 Cadence 宣布合作，将 Cadence InnoStack AI Super Agent 集成进 Rapidus 的 AI 辅助设计解决方案 Raads，面向先进节点（2nm）SoC 设计推进代理式 AI。
关键内容：

  • Rapidus 扩展 Raads 产品线，新增 Raads Navigator 与 Raads Indicator，利用 LLM 为设计者提供质量保证与问题定位协助
  • 新工具与 Cadence InnoStack AI Super Agent 集成，实现跨关键 SoC 工作流的代理式设计编排，从早期架构探索、逻辑实现到最终 signoff 自动协调任务，应用数据驱动优化
  • 目标：相较传统 flow 实现最高 2× 设计周转时间（TAT）缩短
  • 双方将在 CadenceLIVE Japan 2026 联合展示；Rapidus CEO 小池淳义（Atsuyoshi Koike）发表主旨演讲；Cadence CEO Anirudh Devgan 强调先进节点 SoC 需要能编排全生命周期复杂工作流的 AI 智能体，而非仅优化单点任务
核心看点：这是继 Cadence AgentStack/ChipStack/InnoStack/ViraStack/AuraStack 之后，InnoStack 首次深度嵌入代工厂（Rapidus）的 AI 原生设计与制造生态（Raads / RUMS 概念），把代理式 AI 从 EDA 厂商工具延伸到真实先进制程（2nm）设计-制造闭环；直接呼应本站"Agentic AI 重塑 EDA 全流程 + 先进节点产能/设计效率"主线，亦与 07-17 WIR #147 中 Rapidus 采用 InnoStack 的简讯形成完整闭环（本次为更权威的官方专发，含 Raads Navigator/Indicator 与 2× TAT 目标等新增细节）。

🏗️ SemiEngineering 深度：生产级 EDA AI Agent 的架构决策 — 数据湖 + RAG + Agent Skills + MCP + 原生格式解析 + 治理

SemiEngineering 特约撰文（2026-07-09）系统拆解"生产级 EDA/PCB 设计 AI Agent"的架构决策——通用 agentic 框架直接套 EDA 工具会失败，必须在架构层做针对性取舍：
关键架构决策：

  • 领域 grounding：集中式多模态 EDA 数据湖打破团队/工具孤岛，单一事实源；自研 RAG 框架针对 Siemens EDA 工具与方法学优化；Agent Skills 可执行 playbook 跨工作流完成多步任务，每步内置校验与护栏
  • 基础设施兼容：EDA 环境非云原生（敏感 IP、小时/天数级验证任务、TB 级数据），Agent 必须管理长时验证任务不丢状态、集成现有作业调度而非替换、就地操作 TB 级数据
  • 可扩展编排：基于 MCP 的统一编排层实现动态工具发现，防止上下文饱和；子流程由 Agent Skills 自动化、可拼装成跨生命周期多工具工作流，天然多厂商/多模型无关
  • 原生 EDA 数据格式解析：自建领域解析器从 LEF/DEF、GDSII、波形库等真实产物提取精确上下文，汇入数据湖
  • 安全治理：基于角色访问控制、严格沙箱、全面审计追踪、human-in-the-loop 检查点
核心看点：文章是 Siemens Fuse EDA AI Agent 的架构白皮书式解读，把本站长期跟踪的"Agentic EDA 落地要素"（数据闭环 / RAG / Agent Skills / MCP 编排 / 原生格式 / 人在回路治理）系统化呈现；与 06-27 Fuse 发布、06-21 三巨头 AI 平台对比互为补充，为判断 agentic EDA 从演示走向生产提供了可操作的架构清单。

📐 RTL-Sequencer：以序列范式实现可扩展 RTL 时序预测

准确的 RTL 级时序预测是设计自动化长期挑战。现有图方法受限于有限感受野、高复杂度、缺乏信号方向性。本文提出 RTL-Sequencer，一种新颖的序列范式：通过广度优先遍历将逻辑锥线性化为序列，应用现代线性序列模型实现可扩展 RTL 时序预测。

  • 序列线性化：BFS 遍历逻辑锥得到序列表示，规避图方法感受野受限问题
  • 四项协同定制技术：序列洗牌（sequence shuffling）、双向建模（bidirectional modeling）、可微建模（differentiable modeling）、图-序列混合架构（hybrid graph-sequence）
核心结论：大量实验表明 RTL-Sequencer 显著优于 SOTA 基线，推进早期时序优化。
核心创新：将 RTL 时序预测从图范式转向序列范式（BFS 线性化逻辑锥 + 线性序列模型 + 4 项协同技术），突破图方法感受野/复杂度瓶颈——延续本站对 RTL 时序/物理 QoR 预测（HiFi-LLP 延迟预测、AttentionCap 电容提取）与"AI 驱动早期时序优化"主线的跟踪；DAC 2026 接收，Zhiyao Xie 组（港科广）出品，延续该组在时序/IR 预测方向的积累。
标签：RTL 时序预测 · 序列模型 · 逻辑锥线性化 · 可微建模 · 图-序列混合 · 早期时序优化 · DAC 2026
