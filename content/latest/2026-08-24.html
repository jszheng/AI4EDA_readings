📐 HYDRA：面向异构 Chiplet 系统混合 LLM 推理的设计空间探索框架——联合优化芯粒组合、布局、互连带宽与运行时调度，吞吐 1.55×、首 token 延迟降 43.7%

混合 Transformer-Mamba 大语言模型（LLM）提升了长上下文效率，但其异构计算与通信模式使高效硬件加速变得复杂；chiplet 架构通过集成专用计算与存储单元提供可扩展方案，但跨越「静态架构配置 + 动态运行时策略」的设计空间过大、难以穷举。本文提出 HYDRA，一个面向异构 chiplet 系统混合 LLM 推理的综合设计空间探索（DSE）框架，联合探索芯粒组合（chiplet composition）、布局（placement）、片间带宽配置、动态批处理与运行时调度；集成通信感知布局、动态批处理、弹性任务调度，以及捕捉多租户运行时动态的快速 Markov 性能估计器，实现高效且准确的探索。结果：跨所有负载平均吞吐 1.55×、首 token 延迟（TTFT）降低 43.7%，吞吐最高达基线 2.3×。录用于 IEEE/ACM ESWEEK (CASES) 2026，将发表于 IEEE TCAD。属「AI for Multi-Die/Chiplets / 芯粒互连与系统级 DSE」方向的高信号工作，揭示架构—运行时协同设计对大规模 LLM 推理效率的关键性。

📐 MBIST 面积与测试时间自动化估计：堆叠集成框架从 RTL 级参数免综合预测——面积准确度 90.68%、测试时间 96.80%（±10%），较基线 +8.53% / +48.80%

嵌入式存储器在现代 SoC 中占大面积，MBIST（Memory Built-In Self-Test）保障存储可靠性，但引入额外面积与测试时间开销；传统方法依赖完整 RTL 综合与测试向量生成，缓慢且耗资源。本文提出监督学习框架，直接从 RTL 级设计参数（存储数量、字宽、地址深度、端口配置、时钟域）预测 MBIST 面积与测试时间，无需综合。数据集由 Synopsys Design Compiler 与 Intel 增强版 MBIST 工具 MINT 生成（面积 4,470 样本 / 测试时间 624 样本）。面积预测经多项式展开、对数变换与缩放后接入 XGBoost + LightGBM + 神经网络（以 Gradient Boosting 为元学习器）的堆叠集成；测试时间用 XGBoost + LightGBM 经 Ridge 回归融合，超参经 100 次 Optuna 搜索调优。模型在 ±10% 容差内面积准确度 90.68%、测试时间 96.80%，分别较基线提升 8.53% 与 48.80%。属「AI / ML for EDA（DFT 测试规划）」方向，用轻量 ML 替代昂贵的综合预测，支撑存储 IP 开发中的高效设计决策。

⚡ PrefixAgent：LLM 驱动的前缀加法器优化框架——骨干合成 + 结构精化双阶段，函数调用调用 EDA 工具 + e-graph 重写生成训练数据，面积优于基线且随位宽放大

前缀加法器（prefix adder）是基础算术电路，其设计空间随位宽指数增长，优化极具挑战；既有方法在性能、泛化与可扩展性上受限。本文提出 PrefixAgent，一个 LLM 驱动的加法器优化框架：①将问题重构为「骨干合成（backbone synthesis）」与「结构精化（structure refinement）」两个子任务，有效压缩搜索空间；LLM 通过函数调用（function calling）调用工具，基于推理与 EDA 反馈迭代构建骨干并精化局部结构。②这种新视角便于系统性收集大规模高质量监督数据——利用 e-graph（等式图）的重写（rewriting）与等式饱和（equality saturation）能力全面探索前缀加法器解空间；e-graph 的可解释性还能提取细粒度重写轨迹，作为可解释、有效的训练数据。PrefixAgent 在该数据集上微调，显著提升优化能力与推理泛化。实验表明其在近乎所有配置下合成出比基线更小面积的加法器，优势随位宽增大而扩大，且在商业 EDA 流程下仍有效。属「LLM for Hardware / RTL 电路优化」方向，把 LLM 推理、工具调用与形式化 e-graph 搜索结合，是 LLM 驱动电路级优化的代表工作（v2 于 2026-08-20 修订、重现于 08-21 新列表）。

🔬 TTARO：测试时模拟电路表征自适应——提升贝叶斯优化在电路拓扑搜索中的效率（Paul Franzon 组，08-13 公告补录）

模拟电路拓扑搜索（circuit topology search）高度依赖表征（representation）质量，但固定表征难以适配多样设计场景，导致贝叶斯优化（Bayesian Optimization）在庞大且稀疏的电路解空间中效率低下。本文提出 TTARO（Test-Time Analog circuit Representation Adaptation for bayesian Optimization） 框架，在测试时（test-time）自适应调整模拟电路的表征，使其更贴合当前优化任务，从而更高效地引导贝叶斯优化探索电路拓扑空间。方法在「表征—优化」闭环中引入测试时自适应，避免为每种电路手工设计专用表征，提升拓扑搜索的采样效率与最终电路质量。作者含北卡州立大学（NC State）Paul D. Franzon 组，属「模拟与架构 / 模拟电路 AI 优化（贝叶斯优化 + 表征学习）」方向，把测试时自适应（test-time adaptation）思想引入模拟电路自动设计，是模拟 EDA 中表征学习 + 贝叶斯优化的代表工作。（注：本文 2026-08-13 公告，本轮补录以填补此前遗漏。）
